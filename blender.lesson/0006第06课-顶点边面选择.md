## 一、今日学习知识点

### 1. 为什么"选择"要单独学一课

昨天你会按 `Tab` 进编辑模式、会按 `1/2/3` 切点/线/面了。但**进了编辑模式之后，真正的第一步永远是"选中某个东西"**。

建模的全部操作都遵循同一个句式：

> **先选中 → 再操作。**

- 想挤出？先选中一个面，再按 `E`；
- 想倒角？先选中若干条边，再按 `Ctrl+B`；
- 想移动某个角？先选中那个顶点，再按 `G`。

**没选中 = 键盘按烂了也不会有任何反应。** 所以"选择"是编辑模式真正的第一章。今天这一课，就是把"如何精确、快速地选中我想要的那些点/线/面"练成肌肉记忆。

---

### 2. 三种层级下的"选中"长什么样

回顾昨天：`1` 顶点 / `2` 边 / `3` 面。选中后的视觉反馈各不相同——**先学会"看出谁被选中了"**，比急着操作更重要。

| 层级 | 按键 | 未选中 | 选中（橙色/亮色） |
| --- | --- | --- | --- |
| 顶点 Vertex | `1` | 小黑点 | 橙色小点 |
| 边 Edge | `2` | 黑色细线 | 橙色的线 |
| 面 Face | `3` | 深灰填充 | 橙色填充 |

> **关键认知：三种层级的选择是"互相联动"的。**
> 选中一个**面**，它周围的 4 个顶点和 4 条边会跟着变成"被占用"状态；反过来选中一个顶点，它连接的所有面都会亮起一点点橙边。
> 这就是为什么"选面就能挤出整个面"——面本质上代表它那一圈顶点。

**层级切换时选择会保留：** 按 `3` 选中一个面，再按 `1` 切成顶点层级，你会发现**那 4 个顶点还是选中状态**。这个特性非常好用，后面很多技巧靠它。

---

### 3. 基础选择：全选 / 取消 / 反选

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| **全选** | `A` | 当前层级的所有点/线/面全选中 |
| **全不选（取消选择）** | `Alt + A` | 清空所有选择（部分版本也是双击 `A` 反选） |
| **反选** | `Ctrl + I` | 选中的变没选、没选的变选中（Invert） |

> **反选的实战价值：** 想"除了底面之外全选中"，先选中底面，再 `Ctrl+I`，一秒搞定。比手动点十几个面快得多。

---

### 4. 鼠标选择：单击 / 加选 / 减选 / 框选 / 刷选

**点选是基础动作**，但配合 `Shift` / `Ctrl` 就变成了"集合运算"：

| 操作 | 按键 | 效果 |
| --- | --- | --- |
| 单击 | `左键` | 选中它，**并取消之前所有选择**（替换） |
| **加选** | `Shift + 左键` | 把新目标**加入**已有选择（并集） |
| **减选** | `Ctrl + 左键` | 把目标**移出**已有选择（差集） |
| **切换** | `Shift + Ctrl + 左键` | 选中的取消、没选的选中（点哪个翻哪个） |
| **框选** | `B` → 拖框 | 拉一个矩形框，框内全部选中 |
| **刷选** | `C` → 涂抹 | 像画笔一样刷过就选中（**滚轮**调笔刷大小，`右键`或 `Esc` 退出） |
| **套索选** | `Ctrl + 右键` 拖 | 手绘任意形状圈选（很多版本可用） |

**记忆口诀：**
> `Shift` = 我要**加**进来；
> `Ctrl` = 我要**减**出去；
> `Shift+Ctrl` = 你帮我**翻个面**。

> **刷选 `C` 的小坑：** 进刷选模式后发现鼠标变成圆圈、滚轮在缩放视图？——**刷选模式下滚轮改的是笔刷大小，不是缩放。** 确认笔刷大小对了再刷；想缩放视图要先退出（`Esc`）。刷选时按住 `Ctrl` 刷 = 取消选择（橡皮擦）。

---

### 5. 进阶选择：这是今天最值钱的部分

新手动建模慢，90% 是因为**只会一个一个点**。下面这些才是"专业选手"的方法：

#### 5.1 `Alt + 左键`：循环边选择（Loop Select）——**最重要**

在**边层级（按 `2`）**下，`Alt + 左键` 点一条边，Blender 会**沿这条边自动延伸一圈，把整条环线全部选中**。

- **循环边（Edge Loop）**：沿着一排四边形连续延伸的"腰带"，`Alt+左键` 一次选中一整圈；
- **边环（Edge Ring）**：和循环边垂直的那一组平行边。

> 举例：一个立方体，在边层级 `Alt+左键` 点任意一条边 → **一条棱上的所有边被一次选中**。
> 这个操作是后面做"环切、循环加线、整圈挤出"的唯一入口。**今天必须先把这个手感练出来。**

**为什么有时候 `Alt+左键` 只选中一小段？** 因为那条路被"三角面 / 五边面"断了。循环选择要求路线上全是**四边面**。这正是第 17 课"四边面与拓扑"要解决的问题——今天先知道有这回事。

#### 5.2 `L` / `Ctrl + L`：选中相连的整体

| 按键 | 效果 |
| --- | --- |
| `L`（鼠标悬停在某块上） | 选中**鼠标指向的这一整块相连部分**（连在一起的点/线/面） |
| `Ctrl + L` | 把**当前选中部分所连通的所有内容**选中 |

> 场景：两个立方体合并成一个物体但没焊接，鼠标悬浮在其中一个上按 `L` → **整个立方体被选中（哪怕它们肉眼挨着）**。这是判断"模型有没有焊在一起"的最快方法。

#### 5.3 `Shift + G`：按特征选择（Select Similar）

选中一个东西，按 `Shift + G`，可按**相同特征**批量选中其余同类。常用子项：

| 子项 | 含义 |
| --- | --- |
| **Amount of Faces** | 面数相同的面 |
| **Material** | 同材质的对象 |
| **Sides** | 边数相同的面 |
| **Normal**（法线方向） | 朝向一致的面 |

> 实战：想选所有"朝上的面"，选中一个上表面 → `Shift+G` → `Normal` → 全部朝上的面一次选中。做屋顶、做地面时非常好用。

#### 5.4 `Ctrl + 数字键` / `+` `-`：扩选与收缩

- **`Ctrl + 加号（+）`**：向外扩选一圈（Grow Selection）；
- **`Ctrl + 减号（-）`**：向内收缩一圈（Shrink Selection）。

> 用法：选中中心一个面 → 连按 `Ctrl++` → 一圈一圈像水波一样扩散。做花纹、做渐变选区很快。

#### 5.5 选区菜单与"选择全部"技巧

编辑模式下菜单 `Select` 里还有几个宝：

| 菜单项 | 快捷键 | 作用 |
| --- | --- | --- |
| **Select All** | `A` | 全选 |
| **Invert** | `Ctrl + I` | 反选 |
| **Select Loop** | `Alt+左键` | 循环边 |
| **Select More/Less** | `Ctrl + +/-` | 扩/缩 |
| **Select Random** | `Select → Select Random` | 随机选一部分面（做随机着色/散布时用） |

### 6. 为什么"背面的点选不中"？——透视选择（X-Ray）

**这是新手 100% 会遇到的困惑。**

你在一个球上想选中背面的顶点，结果怎么点都点不到——要么选中前面的，要么什么都动不了。

原因是：默认状态下，Blender **只允许选中"你看得见的、最前面的"东西**（正面遮挡背面），这叫**"仅选择可见元素"**。看不见的、被挡住的，鼠标点不到。

**解决方法有两种：**

| 方法 | 操作 | 说明 |
| --- | --- | --- |
| **开启透视（X-Ray）** | `Alt + Z` 或右上角那个"半透明球"图标 | 物体变半透明，**能"穿透"选中背面的点/线/面**（框选 `B` 时尤其有用） |
| **线框模式** | `Z` → 选 `Wireframe` | 只显示线框，所有元素都可见可选 |

> **实用场景：** 用 `B` 框选时，如果只想选"看得见的正面"，就**关掉** X-Ray；如果想"前后一起框选"，就**打开** X-Ray（`Alt+Z`）。
> 这个开关会极大影响框选结果，所以框选前**先确认 X-Ray 是开还是关**。

---

### 7. 选择相关的"配套技能"

选好了要干什么？记住这三个最基础的动作：

| 动作 | 快捷键 | 说明 |
| --- | --- | --- |
| **移动选中** | `G` | 只动选中的点/线/面 |
| **删除选中** | `X` | 弹出菜单选删点/边/面（`Delete` 同样） |
| **隐藏/显示** | `H` 隐藏选中 / `Alt+H` 全部显示 / `Shift+H` 隐藏未选中 | 复杂模型里"隔离处理"某块区域 |

> **框选后最常犯的错：** 框了一大堆，然后按 `G` 一拖，整个形状糊掉了 → `Ctrl+Z` 撤销。
> **安全习惯：选完先看一眼橙色区域对不对，确认了再按 `G`。** 看比改便宜。

---

### 8. 编辑模式下的"软选择"（提前认识一下）

编辑模式左侧工具栏有一个**小圆圈图标（Proportional Editing，软选择）**，快捷键 `O`。

开启后再按 `G`，移动一个顶点会像"捏橡皮泥"一样，**周围一圈跟着被带着动**，越远影响越小（有个虚线影响圈，滚轮调大小）。

- 做有机形状（地形起伏、曲面隆起、钮扣凸起）必备；
- 做硬表面机械时**通常要关掉**（按 `O` 切换开关）。

> 今天不要求掌握，只要知道：**如果你移动一个点，旁边的点莫名其妙跟着动了，检查一下 `O` 是不是被打开了。**

## 三、实操练习任务

> 全程用**默认立方体**（必要时加一个 UV Sphere 做对照）。今天不造新模型，只练"选得准、选得快"。

**1. 观察三种层级的选中反馈**
- 选中立方体 → `Tab` 进编辑模式；
- 按 `1`，`左键`点一个顶点 → 它变橙；
- 按 `2`，`左键`点一条边 → 它变橙；
- 按 `3`，`左键`点一个面 → 它变橙；
- **重点观察**：点了面之后，按 `1` 切到顶点层级 → **那 4 个顶点仍然是选中的**。记住这个"层级联动"。

**2. 全选 / 清空 / 反选**
- 按 `3`（面层级）→ `A` 全选（6 个面全橙）→ `Alt+A` 清空 → `A` 全选 → `Ctrl+I` 反选（变回全不选）；
- 换个玩法：`1` 顶点层级，`左键`单独点一个角 → `Ctrl+I` → 除了这个角，其余 7 个顶点全选中。**体会反选的威力。**

**3. 加选 / 减选**
- 面层级，`左键`点顶面；
- 按住 `Shift` 再点侧面 → 两个面都橙（加选）；
- 按住 `Ctrl` 点刚才那个侧面 → 它被取消（减选）；
- 按住 `Shift+Ctrl` 点底面 → 底面被"翻"为选中。三个修饰键各练 3 遍。

**4. 框选（`B`）**
- 面层级，按 `B` → 鼠标变十字 → 从左上往右下拖一个框 → 框内的面全部选中；
- `Alt+A` 清空，换成从**背面看不到的角度**再框一次，观察结果差异；
- 现在按 `Alt+Z` 打开 X-Ray（物体变半透明），**再框一次** → 观察：**同样一个框，这次连背面的面一起选上了。**
- 总结：**`Alt+Z` 决定"框选是否穿透"，用前先想清楚要哪一种。**

**5. 刷选（`C`）**
- 按 `C` → 鼠标变成圆圈 → 在立方体上涂抹，刷过的面变橙；
- **滚动滚轮** → 圆圈变大变小（注意：此时滚轮改的是笔刷，不是视图缩放）；
- 按住 `Ctrl` 涂抹 → 变成橡皮，把刷到的取消；
- 按 `右键` 或 `Esc` 退出刷选模式。

**6. `Alt+左键` 循环边（今天必须练会的一步）**
- 按 `2` 切到边层级，`Alt+A` 清空选择；
- 对一个侧面，用 `Alt + 左键` 点它的**一条竖边** → **这一整条"棱"上的边会一次全选中**（立方体上会看到 2 条边一起亮）；
- 再试 `Alt+左键` 点**上下方向**的边 → 看到水平方向的一圈选中；
- 在 UV Sphere 上试：`Alt+左键` 点球体上的一圈"经线"或"纬线" → 一整圈被选中，非常爽；
- **第 10 课的"环切"就是建立在这个选择上的**，今天的手感直接决定第 10 课能不能学顺。

**7. 用 `L` 检测"是否焊成一体"**
- `Tab` 回物体模式 → `Shift+A → Mesh → Cube` 加第二个立方体 → 按 `G` 把它挪到紧贴第一个立方体的位置（**只是挨着，没有合并**）；
- 选中第一个立方体 → `Tab` 进编辑模式 → 鼠标悬停在第一个立方体的任意面上 → 按 `L` → **只选中了第一个立方体**（第二个没选上）；
- 重新选两个立方体一起 → `Ctrl+J` 合并成一个物体（Join）→ `Tab` 进编辑模式 → 按 `L` → 观察是否仍然只选中"其中一块"（因为顶点没焊接，它们虽属同一物体但几何上并不相连）；
- 结论：**`L` 判断的是"几何上是否相连"，跟"是不是同一个物体"是两回事。** 这个认知后面做布尔、做焊接时会反复用到。

**8. 扩选与收缩**
- `3` 面层级，单独点立方体的顶面；
- 连按 `Ctrl + 加号（+）` → 观察橙色区域一圈圈向外扩；
- 再连按 `Ctrl + 减号（-）` → 收缩回去。

**9. 反选实战：做"除了底面全都选中"**
- `3` 面层级，点选**底面**；
- 按 `Ctrl+I` → 除底面外全部选中（5 个面）；
- 直接按 `E` `Z` `1.5` 向上挤出 → 得到一个"没有底的盒子加高"的效果 → `Ctrl+Z` 撤销。
- 体会：**反选 + 操作** 是效率极高的组合拳。

**10. 挑战：用"选圈"改造立方体**
- 立方体，`Tab` 回物体模式 → `Ctrl+A → All Transforms`（**铁律，先做！**）；
- `Tab` 进编辑模式，`Ctrl+R` 环切：把鼠标移到立方体上，出现紫色预览线 → **滚动滚轮加 2 条环切线** → 左键确认、右键归位；
- 按 `2` 边层级，`Alt+左键` 选中刚切出来的一圈横向边；
- 按 `S` 缩放这圈边 → 立方体出现"束腰"效果；
- 回到物体模式看整体。**这一步就是后面做瓶子、做柱子收腰的雏形。**

## 五、课后小作业

1. **效率题（必做）**：在立方体上，分别在 `1` / `2` / `3` 三个层级各选中"一条棱上的所有元素"。写下你各自用的**最短操作路径**（提示：`Alt+左键` 在边层级最省事；顶点层级要配合层级联动）。这是本课的核心作业。

2. **对照题**：一句话回答——**为什么背面的顶点用框选选不到？什么快捷键能解决？解决之后，框选结果会有什么变化？**（30 字以上）

3. **分类题**：把下面 8 个操作归类到"**加选**"或"**减选**"：
   `Shift+左键`、`Ctrl+左键`、`Shift+Ctrl+左键`、刷选时按住 `Ctrl`、`Alt+A`、`Ctrl+I`、`A`、`L`。

4. **判断题**：两个互相紧贴但从未焊接的立方体，`Ctrl+J` 合并成同一个物体后，按 `L` 会选中几个？为什么？（提示：`L` 判断的是"几何相连"还是"同属一个物体"）

5. **补速查表**：把本课新增的高频键补进 `Blender学习速查表.md` 的《我的快捷键》表格：
   - `A`（全选）、`Alt+A`（全不选）、`Ctrl+I`（反选）
   - `Shift+左键`（加选）、`Ctrl+左键`（减选）、`Shift+Ctrl+左键`（切换）
   - `B`（框选）、`C`（刷选，滚轮调笔刷）、`Ctrl+右键`（套索）
   - `Alt+左键`（**循环边选择**）、`L`（选中相连）、`Shift+G`（按特征选择）
   - `Ctrl+ +` / `Ctrl+ -`（扩选 / 收缩）
   - `Alt+Z`（X-Ray 透视选择）、`H` / `Alt+H`（隐藏 / 全部显示）
   - `O`（软选择开关）

## 六、小提示与常见坑

- **坑 1：按什么都不动。** 99% 是因为**当前层级下没选中东西**。先按 `A` 全选试试，能动了就说明是选择问题。
- **坑 2：`Alt+左键` 只选了一小段，不是一整圈。** 那条路上有**三角面或五边面**，把循环断了。这不是操作错，是模型的布线不支持——第 17 课会专门讲。
- **坑 3：`Alt+左键` 没反应，反而转了一下视图。** 说明你**不在边层级**（`Alt+左键` 的循环选择主要在边层级生效；面层级下它做的是"环选面"）。先按 `2`。
- **坑 4：框选总选到背面 / 总选不到背面。** 检查 `Alt+Z` 的 X-Ray 状态。**框选前先想清楚要不要穿透。**
- **坑 5：刷选 `C` 时滚轮在缩放视图。** 不是，刷选模式下滚轮改的是**笔刷大小**。想缩放视图先 `Esc` 退出刷选。
- **坑 6：移动一个点，旁边的点跟着动。** 软选择（`O`）被打开了。按 `O` 关掉。
- **坑 7：选完 `Ctrl+I` 之后发现选中范围"太多了"。** 反选是"总体减去当前选择"，先确认当前选中的确实是你要排除的那部分。
- **坑 8：删除了错误的元素。** `X` 弹菜单时看清删的是 `Vertices` / `Edges` / `Faces`——**删面通常连带删掉围成它的边和点**，结果可能和你想的不一样。删完不对就 `Ctrl+Z`。
- **心态提示**：本课看起来全是"鼠标点来点去"，没有漂亮成果，但它是**整个建模阶段的操作底盘**。第 9～16 课的每一个操作（挤出、环切、倒角、镜像、阵列）**起手式都是"先选中"**。今天手指练顺了，往后每一课都会轻松一截；今天偷懒，往后每节课都要回头补。
