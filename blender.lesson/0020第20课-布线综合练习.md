# 第 20 课 · 布线综合练习

> **阶段 3 · 布线 收尾课**（第 17/18/19 课的合卷考试）
> 难度：★★★☆☆　预计用时：60～90 分钟
> 本课不教新工具，把前三课串起来，从零做一件完整硬表面道具。

---

## 一、今日学习知识点

前三课你已经分别掌握了「四边面与极点」「循环边与边流」「布尔后修拓扑」，但它们是分开学的。这一课的核心只有一个字：**串**。

今天要建立的三个意识：

1. **先规划、后动手**——建模前先在脑子里（或纸上）画一遍「线流走向」，再起手。形状是结果，布线是原因（第 17 课）。
2. **布线 = 四边面 + 循环边 + 极点藏好**——三者不是三件事，是一个整体：四边面让循环边能贯通，循环边顺形体走，极点只藏在平坦处。
3. **布尔是手段、不是终点**——布尔能快速开洞，但开完的拓扑是烂的，最后一定要走一遍「修拓扑 → 倒角 → 细分」的收尾流程（第 19 课）。

一句话概括今天：**用一套固定「自检清单」，把散装技能变成肌肉记忆。**

---

## 二、学习目标

学完这一课，你应该能做到：

- [ ] 面对一个带孔的硬表面道具，能先在脑中拆出「主体 → 开洞 → 收尾」三步流程；
- [ ] 独立完成一次「布尔开洞 → 修拓扑」的完整闭环；
- [ ] 用「自检清单」检查自己的模型：全四边面？极点藏好？循环边贯通？细分后不变形？
- [ ] 能自己判断「这里该用布尔、还是该手动布线」。

## 三、实操练习任务

**今日作品：一块「带圆孔的游戏机壳面板」**（一块扁平板子 + 一个圆孔，别小看，这是所有硬表面开孔的基础原型）。

### 步骤 0：先规划（本课灵魂，别跳过）

动手前先回答三个问题：
- 主体是什么形状？（扁平盒子，顶面要开一个圆孔）
- 孔开在哪？（顶面正中央）
- 用什么开孔？（布尔——因为孔在平坦区域，第 19 课结论）

### 步骤 1：起手主体

1. `Shift+A` → Mesh → Cube，做一个长方体（机壳面板）。
2. `S` 缩放成一块「扁平板」，比如 `S Z 0.1 Enter`（压扁）。
3. **`Ctrl+A` → Scale 应用缩放**（铁律第 7 次！不 Apply 后面布尔、倒角都会翻车）。

### 步骤 2：布尔开洞

1. `Shift+A` → Mesh → Cylinder，做一个圆柱（做「孔」的模具）。
2. `S` 缩放圆柱直径到合适大小，`G` 移动它，让它从面板顶面**贯穿**过去（上端露头、下端穿过底面）。
3. 先选中**面板**（被减物体），再按住 `Shift` 加选圆柱（减物体）。
4. 右侧扳手图标 → Add Modifier → **Boolean**，Operation 选 **Difference**，Solver 选 **Exact**，Object 选圆柱。
5. 应用前先 `Ctrl+S` 存个盘（布尔前必另存，第 19 课）。
6. 点 Boolean 修改器右上角下拉 → **Apply**。
7. 在 Outliner 里把圆柱模具隐藏（眼睛图标）或删掉。

现在顶面应该有个圆孔了。

### 步骤 3：修拓扑（本课主菜）

按第 17/18 课的本事修：

1. 进入编辑模式（`Tab`），开 **`Z` → Wireframe** 线框看布线，或用右上角叠加层 Overlays 打开 **Wireframe**。
2. 观察孔周围——现在一定是一圈 n-gon（多边形）和乱七八糟的边流。
3. 用 **`K` 切割刀** 或 **`Ctrl+R` 环切**，从孔的四个方向（上、下、左、右）各拉一条边，把 n-gon 切成四边面：
   - 让孔周围尽量是「放射状的四边面」；
   - 把极点（连接边≠4 的点）尽量赶到**平坦、不变形**的区域。
4. 用 **`Alt+左键`** 检查循环边：孔边那一圈能否顺利贯通？哪里断了就用 `K` 补一条。

> 目标：孔周围一圈「干干净净的四边面环」，没有三角面、没有 n-gon。

### 步骤 4：倒角 + 细分收尾

1. 选中孔的边缘循环（`Alt+左键` 选中孔边一圈），`Ctrl+B` 倒角，给 1～2 段，让孔的边缘有柔和过渡（第 11 课）。
2. `Ctrl+2` 加细分曲面（第 13 课），观察：孔会不会塌、会不会起皱？
   - 塌了 = 边上缺环切，回到步骤 3 加密一圈；
   - 起皱了 = 还有 n-gon 没修干净，回到线框再查。

### 步骤 5：自检清单（背下来）

对着成品逐条过：

- [ ] 全四边面？（`Z` 线框下没有三角面/n-gon）
- [ ] 极点藏好了？（极点都在平坦区，不在孔边、不在圆角处）
- [ ] 循环边贯通？（`Alt+左键` 孔边一圈能完整选中）
- [ ] 细分后不变形？（`Ctrl+2` 后孔是圆的、面是平的）

四条全过，今天就算毕业了。

## 五、课后小作业

把今天的「圆孔面板」升级成 **「带 4 个圆孔 + 1 个方孔的机箱面板」**：

- 4 个圆孔用布尔 Difference 开；
- 1 个方孔可以试试手动布线（`Ctrl+R` + `I` 内插 + `X` 删面），对比布尔和手动的差别；
- 全部开完后，用「自检清单」逐条检查；
- 最后 `Ctrl+2` 细分，保证每个孔都圆润、面板平整。

完成后截图存好，这是你阶段 3 的「毕业作品」。

## 六、常见坑

1. **开孔前忘 `Ctrl+A` 应用缩放** → 布尔/倒角结果歪斜，又是这条铁律。
2. **布尔没选对主次** → 记住：先选「被减的」，再 `Shift` 加选「要减去的」。
3. **孔边缘起皱** → 一定还有 n-gon 没修干净，回线框查，别硬倒角。
4. **修拓扑越修越乱** → 先想清楚线流再切，别乱拉刀（第 18 课「越修越乱」）。
5. **只用布尔、从不修** → 布尔开的洞直接细分必翻车，修拓扑是必经之路。
