## 一、今日学习知识点

### 1. 上一课"长砖"，这一课"划线"

第 09 课你学的是 **`E` 挤出**——从现有的面上再长出新几何。但你会发现一个问题：

> **一个光秃秃的面，你想捏出中间的鼓包，却无从下手——因为面上没有线。**

挤出只能"平移整个面"，**没法让面中间隆起**。要让面能弯曲、能捏形，**首先要在线的地方有"关节"**。

这就轮到今天的主角：**环切（Loop Cut）**，快捷键 **`Ctrl + R`**。

> **一句话理解**：`Ctrl+R` 就是给模型"打网格线"——在现有的面上**横向切出一圈、或多圈新的循环线**。有了这些线，你才能把面捏成曲线。

**打个比方**：一块平整的橡皮泥你没法让它弯，但如果**在中间压出一圈刻痕**，沿刻痕捏就顺手了。环切就是在给模型"压刻痕"。

---

### 2. `Ctrl + R` 到底做了什么？（底层逻辑）

新手容易以为环切是"随便在哪儿切一刀"。**不准确。** 它的实际行为是：

1. 你按 `Ctrl+R` 后，鼠标**悬停到某个面上**，Blender 会**预判出一整圈回路**（沿着模型的环形结构走），并**用黄色高亮预览**出来；
2. 此时**滚动滚轮**可以**增加/减少切线的数量**（1 条、2 条、3 条……）；
3. **左键点击确认** → 这条黄色线被"钉住"；
4. 确认后**再移动鼠标**，这条线会**在整圈上实时滑动**，改变它落在面的哪个位置；
5. **再左键点击（或回车）** → 定下来；**右键 / `Esc`** → 取消。

> **关键点**：`Ctrl+R` **不是"在鼠标那一点切"**，而是**沿着模型已有的环状结构切一整圈**。这是它和"切割刀工具 `K`"最大的区别。

|       | `Ctrl + R`（环切）        | `K`（切割刀 Knife）   |
| ----- | --------------------- | ---------------- |
| 切什么   | 沿模型**已有循环结构**切**一整圈** | 你**手画**一刀，切哪儿切哪儿 |
| 是否连续  | 一整圈连续                 | 可以只切局部、拐弯        |
| 用途    | **均匀加线、布线**           | 需要断续、自定义路径时      |
| 今天学哪个 | ✅ **重点**              | 知道有它即可，以后再学      |

---

### 3. 为什么环切是"布线"的第一步？

第 17 课会正式讲**布线（Topology）**，但今天你先记住一句话：

> **布线好不好，先看有没有线。环切就是"加线"最标准的工具。**

环切产生的是**循环边（Loop）**——一整圈、首尾相连的四边形边。它天然符合两个模型规范：

- **保持四边面**：环切切出来的都是四边形，四边面模型最稳定、最不容易出褶皱；
- **均匀分布**：你可以通过滚动滚轮一次切多条，**均匀地**分布线，这让后续的弯曲更平滑。

> **所以环切不只是"切一刀"，它是你走向专业布线的入场券。** 今天做的一切，都是为第 17～20 课打地基。

---

### 4. 怎么按：环切的两种用法

#### 用法 A：定位置（常用）

```
进编辑模式（Tab）→ 按 Ctrl+R → 鼠标悬停到要切的面
→ 滚轮调线数 → 左键确认 → 鼠标滑动到想要的位置 → 左键/回车 定下
```

> **小技巧**：左键确认后，**再按一次右键**（或输入 `0`）→ 线会**自动落到正中间**（居中）。想要"精确居中切一刀"，这招最快。

#### 用法 B：一次切多条

按 `Ctrl+R` 后，**滚动滚轮向上** → 会同时出现 2 条、3 条……黄色线，**它们自动均匀分布**。适合给圆柱、球体一次性补足分段。

> **新手提醒**：鼠标**放在哪一面**，就沿**那个方向**的环切。切不到想要的环，多半是**鼠标悬停的面不对**——先退出来，把鼠标移到正确的面上再按 `Ctrl+R`。

---

### 5. 环切 vs 细分曲面：都是"加线"，差别很大

新手最容易混的一个问题：环切和"细分曲面修改器"（第 13 课要学）看着都像**加线**，区别在哪？

|       | `Ctrl + R`（环切）     | 细分曲面（Subdivision） |
| ----- | ------------------ | ----------------- |
| 加线后形状 | **基本不变**（只加线，不改外形） | **立刻变圆滑**（把方角磨圆）  |
| 加几条   | 你说了算（滚轮控制）         | 一级翻 4 倍面，指数增长     |
| 用途    | **为后续捏形/弯曲做准备**    | **直接让模型变圆润**      |
| 可控性   | 非常高，一条条精准加         | 相对"整体平滑"          |

> **一句话记住**：**环切是"加关节"，细分是"变圆滑"。** 环切让你**有能力**去捏，细分是**直接帮你磨圆**。两者经常配合使用（先环切加线，再细分才平滑得好）。

---

### 6. 环切的关键前提：必须"有环可切"

`Ctrl+R` 只能**沿着现有的环形结构**切，所以：

- **立方体 / 圆柱 / 球体** → 有完整的环形结构，随便切 ✅
- **一个从球上挤出来的凸起** → 如果它侧面是**一圈四边形**，也能切 ✅
- **三角面扎堆 / 一堆 n-gon（多边面）** → **切不动，或者切出来乱七八糟** ❌

> **这正解释了为什么"要四边面"**：环切只认四边形构成的环。**面越规整，环切越听话。** 今天你会发现——凡是切不出环的地方，那个地方的面多半有问题（三角面、n-gon、或面不连续）。

---

### 7. 环切常见坑（今天就躲开）

| 坑                | 现象                   | 原因 / 正确做法                                      |
| ---------------- | -------------------- | ---------------------------------------------- |
| **切不到想要的环**      | `Ctrl+R` 后没高亮，或高亮在别处 | 鼠标**悬停的面/方向不对**。退出来，把鼠标移到正确的那一面                |
| **切完线偏向一侧**      | 线没有落在中间              | 确认后按**右键**或输入 `0` → 自动居中                       |
| **切了但形状没变**      | 以为切完模型该变样            | 环切**只加线不改形**。要变形得再 `G/R/S` 动这些线                |
| **三角面/多边形上切出怪线** | 切出来歪歪扭扭、连不上          | 该处是 n-gon 或非四边面。先 `Alt+M` 合并 / 重构成四边面再切        |
| **切完模型发黑**       | 面朝向异常                | 开 `Face Orientation` → 红面 `Shift+N`（第 09 课急救包） |
| **切完没法撤销**       | 越切越乱                 | `Ctrl+Z` 撤销；环切前先想清楚要几条                         |
| **在错误的模式切**      | 没反应                  | 环切只在**编辑模式**生效，先 `Tab`                         |

## 二、学习目标

学完本课你应该能：

1. 说清 `Ctrl+R` 的**底层逻辑**（沿环状结构切一整圈），并能说出它和 `K` 切割刀、和"细分曲面"的区别；
2. 熟练完成 `Ctrl+R` → 滚轮调线数 → 悬停定位 → 左键确认 → 滑动定位 → 右键居中/左键定下 的完整流程；
3. 用环切给**圆柱切出腰线**，并配合 `G`/`S` 把圆柱捏成**花瓶**；
4. 判断一个模型**哪里能切、哪里不能切**，遇到切不动能自己排查原因；
5. 明白环切是**布线（第 17 课）的第一入口**——加线是改形的前提。

## 三、实操练习任务

### 练习 1 · 环切对照实验：切了 vs 不切（6 分钟）

1. `Shift+A` 加一个 **Cube**，`Tab` 进编辑模式；
2. 直接选中**顶面** → `E` → `Z` 拉高 → **观察：整体被拉长成一个长方体，但侧面还是"光板"**；
3. `Ctrl+Z` 撤销。这次**先按 `Ctrl+R`**，鼠标悬停在**侧面（竖着的四个面之一）**&#x4E0A;，**滚轮滚 2 下**（切成 3 段）→ 左键 → 右键居中；
4. 现在再选**顶部那一整圈面** → `E` → `Z` 拉高；

> **目的**：亲眼看到——**有线的地方才捏得动**。这一步是本课的核心认知。

---

### 练习 2 · 切线的定位与条数（8 分钟）

1. 加一个 **Cube**，进编辑模式；
2. `Ctrl+R`，鼠标悬停在侧面 → **滚轮向上**，注意黄色线从 1 条 → 2 条 → 3 条，**它们自动均匀分布** → 滚回 1 条 → 左键确认；
3. 确认后**移动鼠标**，看那条线在面上**滑动**——拖到靠边 → `左键`定下 → `Ctrl+Z`；
4. 再 `Ctrl+R` → 左键确认 → 这次**按右键** → 线**自动弹回正中**；
5. 在**顶面**同样操作一次，体会"鼠标悬停在哪个面，就切哪个方向"。

> **目的**：把"滚轮调数量"和"右键居中"两个动作练成肌肉记忆。

---

### 练习 3 · 把圆柱捏成花瓶（14 分钟）

这是本课的主菜，也是**最能出成果**的一步：

1. `Shift+A` 加一个 **Cylinder** → 左下角操作面板设 `Vertices = 16`（省面），删掉**顶面**（选顶面 → `X → Faces`）；
2. `Tab` 进编辑模式 → `Ctrl+R` 鼠标悬停在**侧壁**上 → **滚轮向上切 5 条**（得到 6 段）→ 左键 → 右键居中；
3. 逐条选中**中间那一圈循环边**（`Alt+左键` 点击即可整圈选中，第 06 课学过）→ 按 `S` → 往外**放大**（做出鼓起的瓶肚）；
4. 选中**靠上的一圈** → `S` 往里**缩小**（做出瓶口收窄）；
5. 反复调整几圈线的**半径和高度**（`S` 缩放 / `G Z` 上下移动），直到像一只花瓶；
6. 加个材质颜色，`Z` 切到实体/渲染预览看看。

> **体会**：**先环切加线 → 再 `S` 捏每一圈**，这就是"从圆柱到花瓶"的标准流程。没有环切，这套动作根本无法开始。

---

### 练习 4 · 环切 + 挤出组合技（8 分钟）

记住：环切和挤出是**最佳搭档**——先切出线，再选中由线围成的面去挤。

1. 重新加一个 **Cube**，进编辑模式；
2. `Ctrl+R` 在侧面切 **2 条**（得到 3 段）→ 左键 → 右键居中；
3. 现在切面层级（数字键 `3`）→ 点选**切出来的中间那一圈面**（按住 `Shift` 逐个加选，或用 `Alt+左键` 选整圈）；
4. `Alt+E → Extrude Individual Faces`（第 09 课学过的"各自挤出"）→ 往外挤一点；

> **你会得到一圈均匀的凸起**（像一排铆钉 / 一排按钮）。**这就是环切 + 挤出的威力**——没有环切带来的规整面，这一圈凸起根本做不到这么齐。

---

### 练习 5 · 找一块"切不动"的地方（8 分钟）

1. 加一个 **UV Sphere**，删掉一半（选半个球的面 → `X → Faces`），得到一个半球；
2. 试着在**球面**上 `Ctrl+R` 切几圈 → 一般能切（因为球是规整四边面环）；
3. 现在做一个"坏"的：选中球面上**几个相邻的四边形**→ `F`（或 `Alt+M` 合并顶点）制造一个 **n-gon / 三角面**；
4. 再在这块区域附近 `Ctrl+R` → **观察它切不动，或切出来的线歪斜**；

> **目的**：亲手体验"**环切只认规整的四边面环**"。这就是第 17 课布线存在的意义——**面越干净，环切越听话。**

## 五、课后小作业

1. **概念默写**：用一句话说明 `Ctrl+R`（环切）和 `K`（切割刀）的区别，并说出为什么环切是"布线第一步"。
2. **对比判断**：下面两种需求，你会用哪个？
   - (a) 给一个圆柱**均匀加 6 圈线**，方便后面捏造型；
   - (b) 在一个面上**手画一条拐弯的、只切局部的线**。
3. **小作品**：用"环切 + 缩放"把圆柱捏成一只**花瓶**（课上练习 3 的升级版）——要求至少有 **2 处收窄 + 1 处鼓起**，造型对称。**不允许**用 `Shift+A` 加新物体拼，必须靠环切捏出来。
4. **选做**：给花瓶加一圈"凸起花纹"（环切出线 → 选中面 → `Alt+E → Individual`）。
5. **存档**：`Ctrl+S` 存成 `第10课_环切.blend`，放进你的 Blender 项目文件夹（第 07 课的规范）。**下一课要用。**
6. **预习思考**：想一想——如果一个立方体的**尖角**显得太"硬"，除了环切加线，还有没有更直接的"磨圆"办法？（下一课揭晓）

## 六、常见坑（速查表）

| 坑                | 正确做法                              |
| ---------------- | --------------------------------- |
| `Ctrl+R` 切不到想要的环 | 鼠标**悬停的面/方向**不对，退出来移到正确面再切        |
| 切完线偏向一侧          | 确认后按**右键**或输入 `0` → 自动居中          |
| 切了形状没变化          | 环切**只加线不改形**，要变形得再 `G/R/S` 动线     |
| 三角面/多边形上切出怪线     | 该处不是四边面环，先修成四边面再切                 |
| 切完模型发黑           | 开 `Face Orientation`，红面 `Shift+N` |
| 切在物体模式里没反应       | 环切只在**编辑模式**生效，先 `Tab`            |
| 越切越乱             | `Ctrl+Z` 撤销；环切前先想清楚要几条            |
