## 一、今日学习知识点

### 1. 上一课摆砖，这一课"长砖"

第 08 课你学会的是**摆**——把现成的方块、圆柱摆到位置上。今天开始学**长**：

> **选中一个面，按 `E`，它会"往外再长出一段"。**

这个动作叫 **挤出（Extrude）**，快捷键 **`E`**。它是 Blender 建模里**出镜率最高的操作**，没有之一——你未来做出的 90% 的模型，都是从一个基础体开始，靠几十上百次 `E` 一点点"拉"出来的。

**一句话理解**：`E` 就像给模型"续命"——从现有的面上再生成一层新几何，然后你可以立刻把它拉远、缩放、旋转。

---

### 2. `E` 到底做了什么？（底层逻辑，看懂一次就通）

新手容易以为 `E` 是"把面拉长"。**不准确。** 它实际做了 **3 件事**：

1. **复制**一个和选中面完全重合的新面；
2. 把这个新面**朝某方向移动**（默认是你鼠标动的方向）；
3. **自动在旧面和新面之间补上侧面**（一圈新墙壁）。

> **所以"挤出"最值钱的地方是第 3 步**：它自动帮你接墙，你不用手动去连点连线。**这就是"挤出"和"`G` 移动"最根本的区别。**

**对比一下**：如果第 08 课你选中立方体的一个面，直接按 `G` 往外推——那个面只是**漂出去**了，模型的立方体形状会被拉歪/撕开，**不会补墙**。而按 `E` 再推，**多出一圈侧壁，整体封闭，像把盒子拉长了一段**。

|     | `G`（移动）       | `E`（挤出）           |
| --- | ------------- | ----------------- |
| 干什么 | 把选中的面**整体挪走** | **复制 + 移动 + 补侧壁** |
| 结果  | 模型被拉变形 / 破口   | 模型**长大一段**，且封闭    |
| 用在哪 | 调整位置          | **建模增形**          |

> **记住这条：想"长身体"用 `E`，想"挪位置"用 `G`。混用就会出各种奇怪的破面。**

---

### 3. 怎么按：`E` 之后的标准动作流程

```
1. 进编辑模式（Tab），切到面层级（数字键 3）
2. 点选中一个面（变蓝色）
3. 按 E
4. 移动鼠标 / 按轴向键（X/Y/Z）→ 面被拉出
5. 左键确认（或按 Ctrl+Z / 右键取消）
```

**几个要点**：

- **`E` 之后鼠标动，面就跟着走**。它是"贴着鼠标"的，不用先按 `G`。
- **`E` 之后想锁轴向**：直接按 `X` / `Y` / `Z`，和移动一模一样（第 03 课学过）。
- **`E` 之后想精确数值**：既然它能锁定轴向，也能数字输入——按 `E` → 按 `Z` → 输入 `0.5` → 回车，就精确挤高 0.5。
- **想取消**：`E` 按下去还没确认时，**右键**或 `Esc` 取消这次挤出；如果已经确认了，`Ctrl+Z` 撤销。

> **新手最常犯的错**：按 `E` 之后手一抖点了左键，挤出一小段几乎贴在一起的面（叫"零厚度挤出"），肉眼看不见但已经制造了重叠几何。**养成习惯：`E` 之后先动鼠标，看清楚方向再确认。**

---

### 4. `Alt + E`：挤出菜单（重要！三种挤出方式）

光按 `E` 只是**最基础的"整体挤出"**。真正的威力在 **`Alt + E`** ——按下去会弹出一个小菜单：

| 菜单项                          | 中文             | 作用                     | 什么时候用                                    |
| ---------------------------- | -------------- | ---------------------- | ---------------------------------------- |
| **Extrude Region**           | 整体挤出（= 直接 `E`） | 把**所有选中面当成一整块**挤出去     | 默认情况；挤一个整体造型                             |
| **Extrude Along Normals**    | 沿法线挤出          | 每个面都**沿着自己的面朝向**往外挤    | 对象**弯曲/曲面**时（如球面、圆柱侧面），用普通 `E` 会歪，用这个才均匀 |
| **Extrude Individual Faces** | 各自挤出           | 选中的每个面**各自独立**往外挤，彼此不连 | 一次挤出**一排分离的凸起**（如键盘按键、散热孔、蜂窝）            |
| **Extrude Manifold**         | 流形挤出           | 更聪明的挤出，自动处理复杂转折        | 进阶后再学，今天知道有它即可                           |

**举一个例子秒懂 Region 和 Individual 的区别**：

- 选一个立方体的**顶面 + 前面**两个相邻面，用 **Region** 挤出 → 它们**连在一起**往一个方向走，像一个拐角整体被拉出来；
- 同样选这两个面，用 **Individual** 挤出 → **各自往外走**，拐角会**裂开**变成两片。

> **今天你必须亲手做一次这个对比实验**（写在实操练习里），亲眼看过一次，以后就不会用错。

---

### 5. 挤出的面是"开"还是"封"？——法线翻转这件事

挤出后，**新生成的侧面朝向（法线）通常是对的**，但连着挤很多次、或者挤复杂形状时，偶尔会发现某个面**反了**（Blender 里看起来发黑 /渲染时是黑洞）。

**如何检查**：编辑模式 → 右侧栏 `N` 面板 → `Viewport Overlays` → 勾选 **`Face Orientation`**。开了之后：**正常的面是淡蓝色，反了的面是红色。**

**如何修**：选中那些面 → `Shift + N`（Recalculate Normals，重算法线） → 一般就蓝了。  
如果还不行：`Alt + N` → `Flip`（手动翻转）。

> 新手现在只要记住两句话：**① 觉得面发黑不对劲，先看 Face Orientation；② 红了就 `Shift+N`。** 这是包里必备的"急救包"。

---

### 6. 连续挤出：一层一层往上垒

挤出最大的乐趣是**可以连着来**——每次 `E` 都会基于上一次的结果继续。

比如做一根**灯杆**：加一个 Cylinder（圆柱）→ 顶面 `E` + `Z` 拉高 → 再 `E` 一次 → 再 `E` 一次……每挤一次都能顺手 `S` 缩放（做粗细变化），于是你就能一根杆子做出"粗—细—粗"的造型。

> **这就是硬表面建模的基本功**：**`E` 出来 → `S` 调粗细 → `R` 调角度 → 再 `E`**……循环往复。今天做的杯子、盘子就是这么来的。

---

### 7. 挤出常见坑（今天就躲开）

| 坑                | 现象              | 原因 / 正确做法                                   |
| ---------------- | --------------- | ------------------------------------------- |
| **零厚度挤出**        | 挤出后模型没变化，但面数变多了 | `E` 后立刻左键确认，没移动。`E` 后一定要先动鼠标                |
| **以为 `E` = `G`** | 用 `G` 推面，模型破口   | 想"长"必须用 `E`；`G` 只是挪                         |
| **弯曲面上挤出歪斜**     | 球面/圆柱侧面挤出后越挤越歪  | 改用 `Alt+E → Extrude Along Normals`          |
| **一排凸起粘成一坨**     | 想挤多个独立凸起，结果连成一片 | 改用 `Alt+E → Extrude Individual Faces`       |
| **挤出后面发黑**       | 某些面渲染变黑         | 开 `Face Orientation` 看红蓝，红的面 `Shift+N` 重算法线 |
| **忘了 Apply 变换**  | 挤出方向不对、或缩放很怪    | 进编辑模式前 `Ctrl+A → Scale`（第 05 课铁律）           |

## 二、学习目标

学完本课你应该能：

1. 说清 `E` 的**三步底层逻辑**（复制面 + 移动 + 补侧壁），并能说出它和 `G` 的根本区别；
2. 熟练完成 `E` → 锁轴向 → 数字输入 → 确认 的完整流程；
3. 会打开 `Alt + E` 菜单，能按场景选对 **Region / Along Normals / Individual** 三种挤出；
4. 遇到"面发黑"能自己用 `Face Orientation` + `Shift + N` 排查修复；
5. 把第 08 课的"三块积木台灯"用挤出改造成一个**连体模型**。

## 三、实操练习任务

### 练习 1 · `E` vs `G` 对照实验（6 分钟）

1. `Shift+A` 加一个 **Cube**；
2. 进编辑模式（`Tab`）→ 数字键 `3` 切面层级 → 点选**顶面**；
3. **先按 `G` 再按 `Z`** 往上推 1 个单位 → 观察：**立方体只是变高了，但侧壁没有增加，属于"拉伸变形"**，`Ctrl+Z` 撤销；
4. 同样的顶面，**改按 `E` → `Z` → 输入 `1` → 回车** → 观察：**多出一圈侧壁，像个"叠了两层的盒子"**。

> **目的**：亲手把 `G` 和 `E` 的区别看出来。这是本课最重要的一步。

---

### 练习 2 · 三种挤出方式对比（8 分钟）

1. 加一个 **Cube**，进编辑模式；
2. 选**顶面**，普通 `E` 拉高 → 记住手感；
3. 选**顶面 + 前面**（点两次，按住 `Shift` 加选）→ `Alt+E → Extrude Region` 挤出一段 → `Ctrl+Z`；
4. 同样选这两个面 → `Alt+E → **Extrude Individual Faces**` 挤出一段 → **观察它俩"裂开"各走各的**→ `Ctrl+Z`；
5. 加一个 **UV Sphere**，选几个**弯曲的侧面**，普通 `E` 挤一下（歪斜）→ 撤销 → `Alt+E → **Extrude Along Normals**` 再挤（均匀整齐）。

> **目的**：把 "整体 / 各自 / 沿法线" 三种场景对应上。

---

### 练习 3 · 连续挤出做灯杆（10 分钟）

打开第 08 课存的 `第08课_基础几何体.blend`（或重新搭）：

1. 加一个 **Cylinder**（`Vertices=16` 就够，省面），删掉顶底两个面（选面 `X → Faces`）；
2. 选中顶部那一圈开放的边（`Alt+左键` 选循环边）→ 按 `E` → `Z` 拉高一段 → `S` 缩细；
3. 再 `E` → `Z` → 这次 `S` 放大（做喇叭口）；
4. 再 `E` → `Z` 收口。

> 你会得到一根**粗细有变化的灯杆**——**这就是硬表面建模的节奏感**：`E` → `S` → `E` → `S`。全程不点一个点。

---

### 练习 4 · `Face Orientation` 急救演练（5 分钟）

1. 进编辑模式，按 `N` 打开侧边栏 → `Viewport Overlays` → 勾选 `Face Orientation`；
2. **故意**做一个错误的挤出：选中某个面 → `Alt+E → Extrude Individual Faces` 反复挤几次 → 找找有没有**变红**的面；
3. 选中变红的面 → `Shift + N` 重算法线 → 变回蓝色。关掉 `Face Orientation`。

> **目的**：把这套"急救包"练成肌肉记忆，以后遇到黑洞面不慌。

---

### 练习 5 · 把台灯变成连体模型（12 分钟）

回到第 08 课的台灯（底座 + 灯杆 + 灯罩三个**分开**的物体）：

1. 现在**不用**"三块积木"的思路，而是**从一块开始长**：
   - 加一个 **Cylinder** 当底座 → 顶面 `E` + `Z` 拉出灯杆 → 顶部 `Alt+E`（沿法线或 Region）向外张开做出**灯罩**；
2. 每一步都用 `S` 微调粗细，让它像一根"生长的杆子"而不是"拼的积木"；
3. 加材质（随便给个颜色）、推近看看，对比第 08 课那版**分体台灯**和现在这版**连体台灯**。

> **体会**：连体模型边缘是干净的、没有缝隙的——**这才是真正"建模"出来的东西。**

## 五、课后小作业

1. **概念默写**：用一句话说明 `E` 和 `G` 的区别，并说出 `E` 的**三步底层逻辑**。
2. **三选一判断**：下面三种需求，你会用哪种挤出？（普通 `E` / `Alt+E→Along Normals` / `Alt+E→Individual`）
   - (a) 给一面**墙**上挤出一排**分离的砖块凸起**；
   - (b) 在**球面**上挤出一个凸包；
   - (c) 把**长方体**整体拉长。
3. **小作品**：用"连续挤出"做一根**铅笔**——六边形柱身（`Cylinder Vertices=6`）+ `E` 挤出笔尖（记得 `S` 收细成尖）。不允许用 `Shift+A` 加圆锥来偷懒，必须挤出得来。
4. **选做**：给课上的"连体台灯"开 `Face Orientation` 检查一遍，确保**没有红面**。有问题就 `Shift+N` 修好。
5. **存档**：`Ctrl+S` 存成 `第09课_挤出.blend`，放进你的 Blender 项目文件夹（第 07 课的规范）。**下一课要用。**

## 六、常见坑（速查表）

| 坑               | 正确做法                                 |
| --------------- | ------------------------------------ |
| 用 `G` 推面想"加长"模型 | 加长要用 `E`，`G` 是挪位置                    |
| `E` 后立刻左键，挤出零厚度 | `E` 后先动鼠标看清方向，再左键                    |
| 弯曲面上挤出变歪        | 用 `Alt+E → Extrude Along Normals`    |
| 想挤一排独立凸起却连成片    | 用 `Alt+E → Extrude Individual Faces` |
| 挤出后面发黑          | 开 `Face Orientation`，红面 `Shift+N`    |
| 挤出方向整体不对        | 进编辑模式前先 `Ctrl+A → Scale` 应用变换        |
