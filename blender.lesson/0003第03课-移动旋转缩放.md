## 一、今日学习知识点

### 1. 三把万能钥匙：G / R / S

这是 Blender 里使用频率最高的三个键，从第 3 课用到第 35 课：

| 字母 | 含义（英文） | 中文 | 记忆法 |
| --- | --- | --- | --- |
| **`G`** | **G**rab | 移动 | "抓起来搬走" |
| **`R`** | **R**otate | 旋转 | "转它" |
| **`S`** | **S**cale | 缩放 | "撑大缩小" |

**标准操作三步走**（以移动为例）：

1. 鼠标左键**选中**物体（物体外围出现橙色描边）；
2. 按一下 `G`（不用按住不放！）；
3. **晃鼠标** → 物体跟着走 → **点左键**确认 / **点右键（或 `Esc`）取消**。

> 关键心态：`G` 按一次就够了，之后物体"粘"在你鼠标上，直到你左键落下。
> 很多人第一次按 `G` 死按住不放，结果什么也没发生——**不是按住，是点一下**。

### 2. 轴约束：最核心的技巧

物体会跟着鼠标满屏乱飞，这不可控。所以几乎每次都要**先锁轴**：

| 按键 | 效果 |
| --- | --- |
| 按 `G` 后按 `X` | 只沿 **X 轴**移动（红轴） |
| 按 `G` 后按 `Y` | 只沿 **Y 轴**移动（绿轴） |
| 按 `G` 后按 `Z` | 只沿 **Z 轴**移动（蓝轴） |
| **再按一次同一个键** | 切换成**平面**：`Shift+X` = 在 YZ 平面上移动（不走 X） |
| `Shift` + `X/Y/Z` | 直接就是"排除某轴"的平面移动 |

**轴的记忆法（重要，后面建模全靠它）：**

- **X 轴 = 红 = 左右**
- **Y 轴 = 绿 = 前后（纵深）**
- **Z 轴 = 蓝 = 上下（高度）**

> 颜色一定要记住。以后做杯子（第 15 课）你要沿 Z 轴往上挤，做盘子的边缘你要在 XY 平面上绕，全靠这个颜色直觉。

### 3. 精确数值输入：从"手感"到"工程"

晃鼠标是手感，但包装设计这种活儿经常要**精确尺寸**，所以：

**操作序列**：按 `G` → 按 `Z` → **直接敲键盘数字**，比如敲 `0.5` → 回车。

- 例：`G` `Z` `0.5` `Enter` → 物体沿 Z 轴精确上升 0.5 米；
- 数字可以是负数：`G` `X` `-1` `Enter` → 沿 X 轴往负方向移动 1 米；
- 输入时屏幕左下角/物体旁会显示当前数值，可以按 `Backspace` 改。

**同样的方法适用于旋转和缩放：**

- `R` `Z` `45` `Enter` → 绕 Z 轴旋转 45°；
- `S` `X` `2` `Enter` → X 方向放大 2 倍；
- `S` `2` `Enter` → 三个方向等比放大 2 倍（不按轴键就是整体等比）。

> 单位说明：Blender 默认 1 单位 = 1 米。做包装设计如果想按毫米算，去 `Scene Properties → Units` 把单位改成 `Millimeters` 并设好比例（这个细节第 15 课做实物道具时再深挖）。

### 4. 左下角"操作面板"：事后反悔专用

每次 `G`/`R`/`S` 做完，视口**左下角**都会弹出一个灰色小面板（叫 **Adjust Last Operation / 操作面板**），里面是刚才那一步的**全部参数**：

- 移动的：X / Y / Z 三个位移量；
- 旋转的：角度、旋转轴；
- 缩放的：X / Y / Z 三个倍数。

**为什么要用它**：因为它是**可逆的**。你刚才用鼠标随手一拖，拖歪了，不用 `Ctrl+Z` 重来，直接在这个面板里把数字改成你想要的，物体实时更新。

> 新手一定要养成习惯：做完一次变换，**养成瞄一眼左下角的习惯**。这是"从瞎拖变成可控"的分水岭。

### 5. 轴心的切换（Pivot Point）

按 `S` 缩放时，物体是"以哪个点为中心"缩放？——取决于 pivot 设置，在视口顶部工具栏中间那个小圆点图标（或按 `.` 小数点键调出菜单）：

| 轴心 | 效果 | 什么时候用 |
| --- | --- | --- |
| **Median Point**（默认） | 以选中物体的几何中心 | 日常缩放 |
| **3D Cursor** | 以场景中的红白游标为中心 | 想让物体绕着某个固定点转 |
| **Individual Origins** | 每个物体各自以自己中心 | 多个物体各自缩放 |
| **Active Element** | 以"最后选中的那个"为中心 | 让其他物体对齐到主角 |

> 本课只要知道**有这么回事、能切换**即可，第 4 课（原点与吸附）会专门拆开讲。

### 6. 变换的"复制粘贴"- 快捷补充

| 组合 | 作用 |
| --- | --- |
| `Shift + D` | **复制**物体（连带在原物上的操作，复制后可接着 `G` 挪开） |
| `Alt + D` | **关联复制**（改一个，另一个跟着变） |
| `Ctrl + A` | 应用变换（把缩放/旋转"烙"进模型，第 5 课细讲） |
| `Alt + G` | 位置归零（回到世界原点） |
| `Alt + R` | 旋转归零 |
| `Alt + S` | 缩放归 1（还原大小） |

> `Alt + G/R/S` 这三个是"我不小心搞乱了，恢复出厂"的救命键。

### 7. `T` 键：把侧边工具架调出来

按 `T` 会从视口左侧滑出**工具架**（Toolbar），里面就有 Move / Rotate / Scale 三个按钮，跟 `G/R/S` 等价。

- 好处：手懒的时候点着用；
- 坏处：鼠标要跑很远，效率低。
- **建议：仍然强行练 `G/R/S` 键盘流**，因为后面建模时手速全靠它。

### 8. 变换输入面板（`N` 键）

按 `N` 会从视口右侧滑出 **Item（条目）面板**，里面能看到并**直接编辑**选中物体的：

- Location（位置）X / Y / Z
- Rotation（旋转）X / Y / Z
- Scale（缩放）X / Y / Z

这是另一种精确操作方式：**适合抄数值**，比如视频里 UP 主说"把杯子设成 X=0, Y=0, Z=0.1"，你就直接在这儿填。

## 三、实操练习任务

> 全程只用一个默认立方体 + 偶尔加个球，重点是**把手指练成肌肉记忆**。

**1. 手熟：三种变换各来 5 次**
- 选中立方体 → 按 `G` → 晃鼠标 → 左键确认；
- 再来一次 `G` → 晃到一半 → 按**右键**取消（体会"取消"的手感）；
- `R` → 晃鼠标 → 左键；`S` → 晃鼠标 → 左键。
- **目标：闭上眼都知道按哪个键。**

**2. 单轴练习（今天最重要的 10 分钟）**
- `G` `X` 左键 → 只沿红轴走；
- `G` `Y` 左键 → 只沿绿轴走；
- `G` `Z` 左键 → 只沿蓝轴走；
- 每沿一个轴走完，立刻按 `Ctrl+Z` 回原位，再练下一个。
- 追问自己：**X 轴是屏幕的左右吗？**（答案：不是，是"世界的左右"，你转视角它不变——这正是第 2 课和第 3 课的交汇点。）

**3. 平面约束**
- `G` → `Shift+X` → 晃鼠标 → 观察：物体**只能**在 YZ 平面（前后上下）滑动，绝不左右跑。

**4. 精确数值输入**
- `G` `Z` 敲 `1` `Enter` → 立方体飞升 1 米；
- `S` `2` `Enter` → 整体放大一倍；
- `R` `Z` 敲 `45` `Enter` → 绕 Z 轴转 45°；
- 每次做完**看左下角面板**，确认参数和你输入的一致。

**5. 反悔练习（用操作面板而不是撤销）**
- `G` `X` 晃到左边随手停下 → 去左下角面板把 X 改成 `0.8` → 回车；
- 体会："拖歪 → 改数字修正"比 `Ctrl+Z` 重新来快得多。

**6. 用 `N` 面板抄数值**
- 按 `N`，在 Item 面板里手动输入 Location Z = 0.5，Rotation Y = 30，Scale X = 2；
- 观察立方体变化。**这就是以后跟着视频"照抄参数"的方式。**

**7. 复制与挪位（重点）**
- `Shift+D` → 马上按 `G` `X` `3` `Enter` → 场景里出现第二个立方体，且相距 3 米；
- 再 `Shift+D` → `G` `Y` `-3` → 第三个。
- 现在你有三个立方体、分别站在不同位置。

**8. 轴心体会**
- 选中两个立方体（`Shift` + 分别左键）→ 按 `S` 放大 → 它们以**中间点**为基准散开；
- 切到 Pivot = `Individual Origins` → 再 `S` → 各自以自己为中心放大，位置不动。
- 感受差别。

**9. 归零三连（救命键）**
- 把某个立方体随便搞乱（又转又缩又移）→ 依次按 `Alt+R`、`Alt+S`、`Alt+G` → 它干净地回到原位、原大小、原朝向。

**10. 挑战：搭一个"三分栏"**
- 用今天学的：摆 3 个立方体，X 方向间距 2 米一字排开，等高、同朝向、大小一致。
- 做不出来就重看第 2、4、7 步——这个练习等价于以后"摆一排包装盒"的基本功。

## 六、小提示与常见坑

- **坑 1：以为 `G` 要按住不放。** 是"点一下"，不是"按住"。按一次后松开手，物体跟着鼠标走。
- **坑 2：忘了确认。** 操作中左键 = 确认，右键 / `Esc` = 取消。如果发现按了半天没反应，看是不是还停在"待确认"状态。
- **坑 3：约束轴按错了不知道。** 按 `X` 之后只有红轴会亮，晃鼠标只能沿红轴走。晃不动别慌，看看是不是已经锁了某个轴。
- **坑 4：数字输入没生效。** 敲数字前必须**先按 `G/R/S` 并且已经处在"操作中"状态**；如果你已经左键确认了，再敲数字是没用的。
- **坑 5：缩放后模型"比例坏了"。** 有些操作（比如修改器、倒角）会被非等比缩放影响，老手习惯做完缩放按 `Ctrl+A → Scale` 应用掉。第 5 课会讲透。
- **坑 6：用鼠标拖过头，越拖越歪。** 记住：**拖 → 停车 → 去左下角改数字**，比反复撤销快 10 倍。
- **手感提示**：今天是最需要"重复"的一课，建议至少练满 35 分钟手动。手指形成肌肉记忆后，后面 32 课都会轻松一大截。
