## 一、今日学习知识点

### 1. 上一课"加线"，这一课"磨角"

第 10 课你学的是 **`Ctrl+R` 环切**——给模型的**面**上**加线**。今天学的是**另一件互补的事**：给模型的**边（棱角）削掉、磨圆**。

> **一句话理解**：倒角（Bevel，快捷键 `Ctrl + B`）就是把模型**尖锐的边**削成**一条小斜面或小圆角**。

**打个比方**：你手里一块方方正正的木头，四个棱角扎手。用砂纸把棱角**磨掉一圈**——棱还是那条棱的位置，但不再锋利，变成一道**圆润的过渡**。倒角就是给模型"磨棱角"。

> **记住这条行业经验**：**现实中的物体，几乎没有绝对锋利的直角。** 桌边、手机边框、杯子口、机箱棱线——全都有微小的圆角。所以给模型倒一点角，**立刻就有"真实感"和"高级感"**。这是硬表面建模最出效果的一招。

---

### 2. `Ctrl + B` 到底做了什么？（底层逻辑）

新手容易以为倒角是"切一刀"。**不准确。** 它的实际行为是：

1. 你**先选中一条边**（或一整圈边）；
2. 按 `Ctrl+B` → 此时移动鼠标，**那条边会被"劈开"并往两侧推进**，中间生出一条新的面；
3. **移动鼠标 = 控制倒角宽度（Width）**：离得越远，倒出来的面越宽；
4. **滚动滚轮 = 控制段数（Segments）**：1 段 = 一条**斜面（斜切）**，2 段以上 = **圆角**；
5. **左键点击 / 回车 = 确认**，**右键 / `Esc` = 取消**。

> **关键点**：倒角**作用于"边"**（也作用于顶点，见第 5 节）。它是**把一个尖角替换成一段过渡面**，而不是切掉整块。

---

### 3. 倒角 = 1 段 vs 多段（本课最核心的一个参数）

这是你最需要亲手感受的差别：

| 段数 Segments | 结果 | 常见用途 |
| ----------- | -------- | ---------------- |
| **1 段**      | 一条**平直的斜面**（斜切） | 做**切角风格**、边线拉丝高光 |
| **2 段**      | 开始出现折线 | 过渡 |
| **3～5 段**   | 明显**圆角** | **绝大多数硬表面收边**（最常用） |
| **很多段**     | 近乎半圆、面数暴涨 | 只有做**大圆角特写**才需要 |

> **一句话记住**：**滚轮加段数 = 把"斜切"变成"圆角"。** 做硬表面时**最常用 2～3 段**——既圆润，又不浪费面数。段数太多，模型会变得又重又难改。

---

### 4. 怎么按：完整流程 + 左下角操作面板

```
选中一条边（编辑模式）→ 按 Ctrl+B → 移动鼠标定宽度
→ 滚轮调段数 → 左键 / 回车 确认
```

确认后，视线移到**左下角的操作面板**（`Ctrl+B` 后立刻出现，点小三角展开），里面有三个关键参数：

| 参数 | 作用 | 新手怎么调 |
| ------------- | ---------------------------- | -------------- |
| **Width（宽度）** | 倒角的**宽窄** | 数值越大，棱角消得越多；0.02～0.05 是常见"小收边" |
| **Segments（段数）** | 前面说的 1 = 斜切、多 = 圆角 | 一般 2～3 |
| **Profile（轮廓）** | 圆角的"胖瘦" | 0.5 = 标准圆弧；调小/调大 = 变成内凹或外凸的特殊造型 |

> **为什么要用面板？** 用鼠标拖只能凭手感，**在面板里填数字才能精确、才能复现**。倒角宽度尤其重要——**想做出"整齐一致"的收边，一定要靠数值控制。**

> **补充**：面板里还有 **Clamp Overlap（限制重叠）**。它防止倒角宽度太大、把相邻的面**挤穿**。**保持勾选**，新手别关。

---

### 5. 倒角不只倒"边"，还能倒"顶点"

有时候你想要的是**把一个尖顶磨成一个小圆面**（比如做一个圆角锥顶、或者打磨一颗钻石的尖端），这时候选**顶点**再倒角：

- 选**顶点** → 按 `Ctrl+B`（有些版本是 `Ctrl+Shift+B`，或走菜单 `Edge → Bevel Vertices`）→ 移动鼠标 → 顶点会被削成一个**小三角/小多边形面**。
- 另一个更快的入口：在编辑模式按 **`Alt + E`**（第 09 课学过的挤出菜单旁边），或直接看**顶部菜单 `Edge（边）`** 里的 **Bevel**。

> **新手提醒**：**边倒角（`Ctrl+B`）是主菜，顶点倒角是偶尔才用的小工具。** 今天重点练边。按不出来别慌，多半是**没选中边**（切换到边层级 `2` 再选）。

---

### 6. 倒角 vs 环切：都改模型，方向完全不同

|       | `Ctrl + B`（倒角）        | `Ctrl + R`（环切）      |
| ----- | -------------------- | ------------------ |
| 作用对象  | **边（棱角）**            | **面**              |
| 做了什么  | **把尖角削成斜面/圆角**       | **在面上加一圈新线**       |
| 形状变化  | **立变**（棱角立刻没了）        | **基本不变**（只加线）      |
| 用途    | **让模型精致、真实、有高光**     | **为捏形/弯曲做准备**      |
| 记忆    | **倒角 = 磨边**          | **环切 = 加线**        |

> **一句话记住**：**环切是"加关节"，倒角是"磨棱角"。** 两者经常**先后搭配**——先环切加线控制形状，再倒角收边让棱线漂亮。

---

### 7. 最常见的坑：倒角的"宽度不均匀"

这是本课**最重要的一个坑**，也是 90% 的新手都会踩的：

> **如果你在缩放过的物体上直接倒角，倒出来的边会一边宽一边窄、甚至严重变形。**

**原因**：你在物体模式用 `S` 缩放物体时，Blender 记录的是**缩放值（Scale ≠ 1）**，而不是真正的几何尺寸。倒角计算用的是**真实几何**，于是同一个"0.02 宽度"，在**被拉长的方向**和**没被拉长的方向**上，视觉宽度就完全不一样了。

**解法（对应第 05 课的铁律）**：

```
在物体模式选中物体 → 按 Ctrl + A → 选 Scale（应用缩放）
→ 此时 Scale 变回 1,1,1 → 再进编辑模式倒角 → 宽度就均匀了
```

> **记住这条铁律**：**进编辑模式动刀之前，先 `Ctrl+A` → Scale 应用缩放。** 这一条今天务必刻进肌肉记忆——它以后会在**倒角、挤出、UV 展开、法线**等各种场合反复救你。

## 二、学习目标

学完本课你应该能：

1. 说清倒角的**底层逻辑**（把边削成斜面/圆角）和它跟**环切**的区别；
2. 熟练完成 `Ctrl+B` → 拖鼠标定宽度 → 滚轮调段数 → 左键确认 的流程，并会用**左下角面板**精确调控 Width / Segments / Profile；
3. 说清 **1 段 = 斜切、多段 = 圆角** 的差别，知道硬表面**通常用 2～3 段**；
4. 掌握**核心铁律**：倒角前先 `Ctrl+A` 应用缩放，否则倒角宽度不均匀；
5. 给一个立方体倒角，把它从"积木块"变成一个**有真实高光收边的漂亮硬表面模型**；
6. 会用**顶点倒角**处理尖顶。

## 三、实操练习任务

### 练习 1 · 第一刀：给立方体倒圆角（6 分钟）

1. `Shift+A` 加一个 **Cube** → `Tab` 进编辑模式；
2. 按 **`2`** 切到**边**层级，`Alt+左键`点一条竖边 → 或用 `Shift+左键` 把**四条竖边**都选上；
3. 按 **`Ctrl+B`** → **慢慢移鼠标**，看那几条边被削开 → **滚轮向上滚到 3 段** → **左键确认**；

> **目的**：第一次亲眼看到"棱角被磨圆"。多按几次 `Ctrl+Z` 反复试，**感受鼠标距离和滚轮段数分别控制什么**。

---

### 练习 2 · 1 段 vs 3 段 vs 8 段的对比（8 分钟）

1. `Shift+A` 加三个 Cube，横向排开（各 `G X` 移动分开）；
2. 第一个：选中一条边 → `Ctrl+B` → 保持 **1 段** → 确认；
3. 第二个：同位置边 → `Ctrl+B` → 滚轮加到 **3 段** → 确认；
4. 第三个：同位置边 → `Ctrl+B` → 滚轮加到 **8 段** → 确认；
5. 打开左下角面板，逐个点开看 **Width / Segments / Profile** 三个数值，改成一样的 Width 对比；
6. 再玩一个：把 Profile 从 0.5 调到 **0.2 和 0.8**，观察圆角变成"内凹"或"外凸"的怪形状。

> **目的**：把"段数 = 圆滑程度""Profile = 圆角胖瘦"这件事**看进眼睛里**。这一步之后，你调参数就是凭理解而不是凭猜。

---

### 练习 3 · 全部边倒角：让立方体"高级化"（10 分钟）

这是本课最出效果的一步：

1. `Shift+A` 加一个 **Cube** → `Tab` 进编辑模式 → `A` 全选；
2. 按 **`Ctrl+B`** → **轻轻移一点点鼠标**（做一道**细收边**）→ 滚轮加到 **2 段** → 左键确认；
3. 回到物体模式 → 给个金属材质（颜色灰、Metallic 拉满、Roughness 0.3）→ `Z` 切到**渲染预览 / Eevee**；
4. 加一盏灯或直接看环境光下**棱线处的高光**——你会发现，**正是这道小倒角在边缘拉出了一条漂亮的高光**，物体立刻从"塑料方块"变成"有质感的产品"。

> **目的**：理解 **倒角在硬表面建模里的真正价值——它是"高光收边"**。棱边没有倒角，高光会断成一截截；有了倒角，光会沿着倒角面**连续地流淌**。

---

### 练习 4 · 踩一次"缩放后倒角"的坑（10 分钟）

**故意踩坑，才能记牢。** 分两组对照：

1. **错误组**：加一个 Cube → 物体模式 → `S` → `Z` → 输入 `3`（把它拉成高瘦块）→ **不要 `Ctrl+A`** → `Tab` 进编辑模式 → 选四条竖边 → `Ctrl+B` 拖一点点 → **观察：不同方向的边倒角宽窄明显不一样，甚至有的边倒穿了！**
2. `Ctrl+Z` 撤销到原始立方体；
3. **正确组**：物体模式 → **`Ctrl+A` → Scale**（左下角确认"Scale"）→ 看到右侧 N 面板里 Scale 变回 `1,1,1` → 再 `S Z 3` 拉高 → **再 `Ctrl+A` → Scale** → 进编辑模式倒角 → **这次四条边宽度完全一致**。

> **目的**：亲手体验 `Ctrl+A 应用缩放` 这一铁律为什么不能省。**建议把这一步的两种结果都截图**，以后忘了就翻出来看。

---

### 练习 5 · 顶点倒角 + 综合小道具（10 分钟）

1. 加一个 **Cube** → 编辑模式 → 切到**顶点层级（`1`）**；
2. 选中**顶面四个顶点** → `S` 缩小一点 → 先把顶面收小（做个梯形台）；
3. 选中**顶部某个尖角顶点** → 按 `Ctrl+B`（如无效试菜单 `Edge → Bevel Vertices`）→ 拖鼠标 → **尖角被削成一个小三角面**；
4. 综合：给这个台子**所有边**来一次 `Ctrl+B` 2 段小倒角 → 加个金属材质 → 渲染看一眼；
5. `Ctrl+S` 存成 `第11课_倒角.blend`。

> **目的**：把今天学的"边倒角 + 顶点倒角"组合成一个小完整模型，也顺便为第 15 课的硬表面道具打底。

## 六、常见坑（速查表）

| 坑 | 现象 | 正确做法 |
| ------------------- | ------------------ | ---------------------------------------- |
| **倒角宽度不均匀** | 同一个宽度，有的边宽有的边窄 | **先 `Ctrl+A` → Scale 应用缩放**，再进编辑模式倒角（本课核心） |
| **倒角后模型破面/穿帮** | 面互相穿插、出现黑面 | 倒角宽度太大、或没勾 **Clamp Overlap**；把 Width 调小 |
| **倒角出来是斜切不是圆角** | 棱角没变圆 | **滚轮加段数**（1 段 = 斜切，2 段以上 = 圆角） |
| **段数给太多，模型变重** | 改不动、卡顿 | 硬表面一般 **2～3 段**就够，别上 8、16 |
| **在三角面/n-gon 上倒角异常** | 倒出来歪斜、连不上 | 该处面的结构不好，先修成四边面（呼应第 10、17 课） |
| **按 `Ctrl+B` 没反应** | 什么都没发生 | 多半**没选中边**：切到边层级（`2`）选定边再按 |
| **在物体模式里倒角** | 无效 | 倒角只在**编辑模式**生效，先 `Tab` |
| **倒角越倒越乱** | 无法收拾 | `Ctrl+Z` 撤销；倒角前先选定**要处理的那几条/那一圈边** |

**第 12 课：镜像修改器（Mirror Modifier）**

今天你学会了给棱角"**磨圆**"。下一课开始接触**修改器（Modifier）**——Blender 里最省力的一类工具。第一个是**镜像修改器**：你**只做物体的左半边**，Blender **自动帮你镜像出右半边**，而且**左右永远保持同步**——改一边，另一边跟着变。做**对称物体**（人脸、飞机、椅子、绝大多数产品）时，效率直接翻倍。**下一课见。**
