## 一、今日学习知识点

### 1. 今天是个分水岭：你第一次接触"修改器"

前面 11 课，你改模型全靠**手动**——`E` 拉、`Ctrl+R` 切、`Ctrl+B` 磨，改一次就落一次实。**从今天起，你开始用一种更聪明的方式：修改器（Modifier）。**

> **一句话理解**：修改器 = **给物体挂上一个"自动加工模块"**，它**实时**地对模型做某种加工，而**原模型本身没变**。你不满意，随时能关掉、改参数、删掉。

**关键特性（先记住这四条，今天全程都在用）**：

| 特性 | 含义 | 好处 |
| ---------------- | -------------------------------- | ------------------------ |
| **非破坏性** | 只改"显示结果"，不动原始数据 | 随时反悔，不心疼 |
| **可堆叠** | 一个物体能挂**好几个**修改器，从上往下依次加工 | 像流水线，一层层做 |
| **可开关** | 每个修改器前面的小眼睛图标可关掉看原样 | 一秒对比"改前/改后" |
| **要 Apply 才落地** | 想让它变成"真实几何"必须手动应用 | 决定你要不要"固化" |

> **打个比方**：手动建模像**直接在木头上雕刻**——刻错了很难补。修改器像**给木头套了一套自动模具**——模具一直在工作，但木头还是那块木头；你把模具拆了，木头完好如初。

---

### 2. 修改器藏在哪里？先认门

在**右侧属性面板**（默认最右边那竖排图标）里，找到**扳手图标**——那就是 **Modifier（修改器）属性**。

```
右侧属性面板 → 点【蓝色扳手图标】→ 面板顶部有【Add Modifier】按钮 → 选类型
```

打开后你会看到：

- 顶部按钮 **Add Modifier**（添加修改器）——点它弹出**分类菜单**；
- 菜单里按类别分组：**Generate（生成）／ Deform（形变）／ Physics（物理）** 等；
- **一切修改器都在这个菜单里找**，今天要的 **Mirror** 在 **Generate（生成）** 分类里。

> **新手提醒**：修改器是**加在"整个物体"上**的（**物体级别**），不是加在某个面上。所以加它之前**先在物体模式选中这个物体**，不用进编辑模式。

---

### 3. Mirror（镜像）到底做了什么？

> **一句话理解**：镜像修改器 = **把模型沿某条轴"翻个个儿"，复制出对称的另一半**。

**打个比方**：你拿一张纸对折，在**半边**上剪出一个人形，展开后——**另外半边自动对称出现，一模一样**。镜像修改器就是这个"对折展开"的自动版，而且**折叠线永远比着手工剪齐整**。

它的核心参数只有三个，但每一个都关键：

| 参数 | 作用 | 新手建议 |
| --------------- | ----------------------------------- | ------------------------ |
| **Axis（轴）X / Y / Z** | 沿哪条轴做镜像（哪条轴是"对折线"） | 绝大多数左右对称物体用 **X** |
| **Mirror Object（镜像参照物）** | 以**哪个物体**为对称中心（默认=自身原点） | 新手先不动，默认即可 |
| **Clipping（缝合/吸附）** | 中间接缝处的点**自动吸到轴上、不穿过** | **务必勾上**（本课核心之一） |
| **Merge（合并）** | 把中间**重合的顶点合并成一个**，消除缝隙 | **勾上**，并把 Merge 阈值调到 0.001～0.01 |

---

### 4. 最重要的一件事：镜像"以哪里为对称中心"？

这是新手最容易蒙的地方，记住这句话：

> **镜像修改器默认以"物体自己的原点（Origin）"所在的轴为对折线。**

翻译成人话：**如果物体的原点在它左侧边缘，镜像出来的另一半就在右边；如果原点在正中间，镜像出来的就是左右对称的整身。**

这就直接串起了**第 04 课的原点**知识：

- 你想让一个立方体变成"左右对称的整块"→ **原点必须在正中间**（默认 Cube 就在正中，所以直接加 Mirror 会得到重叠的两个立方体，看着像没变——**这是我们练习 1 要踩的坑**）；
- 你想"做左半边 → 镜像出右半边"→ 先把**原点挪到那条对称缝上**（用第 04 课的 **`Set Origin → 3D Cursor`** 或 **`Set Origin → Bounds Center`**）。

> **记住**：**镜像的中心 = 物体的原点。原点在哪，对折线就在哪。** 这一条想通，镜像 90% 的困惑就没了。

---

### 5. 正确的"半边工作流"（本课核心套路）

**这是镜像修改器真正的用法，请务必按这个顺序练：**

```
① 加一个立方体（或任意体块）
② 把物体原点挪到"对称缝"位置（例如它的左边缘，即 x=0 平面上）
   → 物体模式：Ctrl+A 应用缩放 → Set Origin 到缝上
③ 删掉不需要的另一半：进编辑模式 → Alt+Z 开透视 → 框选右半边 → X 删除
   → 现在你手里只剩"左半边"
④ 加 Mirror 修改器：扳手面板 → Add Modifier → Generate → Mirror → 勾 X 轴
   → 瞬间，右半边被自动"镜像"出来，模型恢复完整，而且左右绝对对称
⑤ 勾上 Clipping（+ Merge）→ 中间缝隙消失、完美缝合
⑥ 之后所有捏形，都只在【左半边】动手，右半边实时跟随
   → 这就是"改一边，另一边自动同步"的爽点
```

> **一句话记住**：**只做半边，另一半交给 Mirror。** 做**人脸、头盔、飞机、汽车、椅子、瓶子、绝大多数产品**——只要能左右对称，就该用这套流程。

---

### 6. 修改器栈：顺序不同，结果不同（进阶但重要）

修改器面板里，多个修改器是**从上往下依次执行**的。这就是"**修改器栈**"。顺序会直接影响结果：

- **Mirror 放在 Subdivision（细分曲面，第 13 课）之前**：先镜像再细分 → 两侧各自细分，**中间接缝处可能不连贯**（有折痕）；
- **Mirror 放在 Subdivision 之后**：先细分再镜像 → 更平滑，但面数翻倍更早；
- **实战经验**：**Mirror 一般放在最上面（最先执行）**，把对称先做好，再让细分、倒角等去加工。**倒角（Bevel 修改器）通常放在 Mirror 之后**，才能保证接缝处也被倒到。

> **操作**：拖动修改器卡片右上角的**十字手柄**即可上下调整顺序；点卡片左边**小眼睛**开关；点**小叉**删除。

---

### 7. Apply（应用）vs 不 Apply：什么时候该"固化"？

镜像出来的另一半，**默认只是"显示出来的"，并没有变成真实顶点**。什么时候要把它坐实？

| 情况 | 建议 |
| ---------------------------------- | ---------------------------- |
| 还想继续调整对称、还要改参数 | **不要 Apply**，保留修改器 |
| 模型定稿、准备导出 FBX/glTF/STL | **必须 Apply**（导出前把修改器应用掉） |
| 想手动精修另一半（做不对称细节） | **Apply 后**再进编辑模式单独改 |
| 想再挂别的修改器、但顺序理不清 | 可先 Apply 简化 |

**怎么 Apply**：修改器卡片右上角小三角 **▽** → **Apply（应用）**；或按 **`Ctrl + A`**（在物体模式，注意是"Apply Modifier"，跟"应用缩放"不同，别搞混）。

> **坑**：**Apply 之后就"回不去"了**——修改器被消耗掉、参数没了。所以**Apply 前先 `Ctrl+S` 存一份**，或复制一个备份物体。

## 二、学习目标

学完本课你应该能：

1. 说清**修改器**是什么，以及它的三大特性：**非破坏性、可堆叠、要 Apply 才落地**；
2. 在**右侧扳手面板 → Add Modifier → Generate → Mirror** 正确加出镜像修改器；
3. 理解**"镜像中心 = 物体原点"**这条核心逻辑，并会用 **`Set Origin`** 把对折线摆到正确位置；
4. 完整走通一遍**"只做半边 → Mirror → 缝合"**的工作流；
5. 会用 **Clipping + Merge** 消除中间缝隙，做出**干净无缝**的对称模型；
6. 知道**修改器栈顺序**会影响结果，初步形成"Mirror 放最前、倒角放后面"的排序意识；
7. 明白 **Apply 与不 Apply** 的取舍，并知道**导出前要 Apply**。

## 三、实操练习任务

### 练习 1 · 先踩坑：直接把 Mirror 加在完整立方体上（6 分钟）

**故意先错一次，把"原点"这件事钉进脑子。**

1. `Shift+A` 加一个 **Cube**（默认原点在正中心）；
2. 物体模式选中它 → 右侧**扳手图标** → **Add Modifier → Generate → Mirror**；
3. **看结果**：模型看起来**几乎没变化**，只是……左边多出了一个**重叠**的立方体（进入 X-Ray 或稍微移动一下就能看到两半叠在一起）；
4. **想明白为什么**：因为**原点在正中间**，镜像出来的另一半跟原来**完全重叠**——所以你才"看不出变化"。

> **目的**：亲手感受"**镜像中心 = 原点**"。这一步会让你以后一加 Mirror 就先去想"原点在哪"。

---

### 练习 2 · 正解：完整走一遍"半边 → Mirror"工作流（15 分钟 · 主菜）

这是**本课最核心**的练习，请一步不落地走一遍：

1. `Shift+A` 加一个 **Cube**；
2. **把原点挪到对称缝上**：物体模式 → `Ctrl+A` → **Scale**（应用缩放，铁律！）→ 然后 `Shift+S`（或右键菜单）→ **Set Origin → 3D Cursor**，前提是**先把 3D 游标移到左侧沿中心**：
   - 简单做法：`Shift+C` 把游标归零到世界原点 → 再把立方体的**左边缘**对齐到 x=0（`G X` 移动，或用第 04 课的吸附）；
   - 更省事的做法：直接 `Shift+A` 加 Cube 后，进入编辑模式，用 **`Shift + S`** 相关吸附或直接把游标放在左边缘中点，再 `Set Origin → 3D Cursor`；
3. **删掉右半边**：进编辑模式 → 切到**面层级（`3`）** → `Alt+Z` 开 X-Ray → **框选右半边所有面** → 按 **`X` → Faces（面）** 删除；
   - 现在是"只剩左半边"的状态；
4. **加镜像**：回物体模式 → 扳手面板 → **Add Modifier → Generate → Mirror** → **只勾 Axis 的 `X`**；
5. **瞬间**——右半边被自动镜像出来，模型恢复完整，**左右绝对对称**；
6. **勾上 Clipping**（Mirror 面板里的复选框）→ 再展开 **Merge** 并勾选，阈值填 **0.001**；
7. 进编辑模式，**只移动左半边的某个顶点**，看**右半边实时跟着动**——这就是镜像的爽点。

> **目的**：把上面第 5 节的"半边工作流"变成**肌肉记忆**。以后做任何对称物体，第一反应就是这个流程。

---

### 练习 3 · Clipping 到底救了你什么？（8 分钟）

**对比实验，看清 Clipping 的作用：**

1. 拿练习 2 的模型 → 先在 Mirror 面板里**取消勾选 Clipping**；
2. 进编辑模式 → 把**靠近对称缝的那个顶点**往左拖一点点 → **看到中间裂开一条缝**；
3. `Ctrl+Z` 撤销 → **重新勾上 Clipping** → 再拖那个顶点 → **顶点被"吸"在对称缝上，怎么也过不去，缝隙永远不存在**；
4. 再试：把 **Merge** 关掉 → 你会发现中间虽然不穿模，但**重合一排顶点，渲染时可能有黑缝/闪烁**（因为两个面重叠在一起）；
5. 重新勾上 **Merge，阈值 0.001** → 中间顶点被合并，**干净无缝**。

> **目的**：理解 **Clipping = 防止中间穿模，Merge = 消除重叠顶点**。这两个勾**是做镜像的标配**，务必都开。

---

### 练习 4 · 修改器栈顺序实验（8 分钟）

1. 拿练习 2 的模型 → 给它再加一个 **Subdivision Surface（细分曲面）** 修改器（先不管参数，默认即可）；
2. 现在栈里顺序是 **Mirror 在上、Subdivision 在下**：
   - 拖动 **Subdivision 的十字手柄**，把它移到 **Mirror 上面** → 观察中间接缝处的变化（先细分再镜像 → 中间可能出现明显折痕/不平滑）；
3. 再拖回来（**Mirror 在上、Subdivision 在下**）→ 对比，通常这样**接缝更干净**；
4. **结论**：记住 **Mirror 一般放最上**，让对称先成立，再让其它修改器加工。

> **目的**：建立"**修改器是有顺序的流水线**"这个意识。第 13 课细分曲面会再遇到它。

---

### 练习 5 · 综合小道具：做一个对称的"茶几/小桌"（12 分钟）

1. `Shift+A` 加 Cube → 编辑模式 → 拉伸成一个**桌腿**（`E` 挤出变高）→ 细节随意；
2. 按练习 2 的流程：**原点挪到对称缝 → 删掉右半边 → Mirror + X 轴 + Clipping + Merge**；
3. **再给镜像加一条 Y 轴**（Mirror 面板里同时勾 `X` 和 `Y`）→ 你会得到**四条桌腿**（两两对称）——这就是"一个镜像干四份活"；
4. 加一块桌面：`Shift+A` 加 Cube → `S` 压扁 → 对准四条腿上方；
5. 给桌腿加 **Bevel 修改器**（第 11 课的倒角，这里用修改器版）2 段小倒角，让棱线漂亮；
6. **注意栈顺序**：Mirror → Bevel → Subdivision，拖动确认顺序合理；
7. `Z` 切渲染预览看一眼 → **`Ctrl+S` 存成 `第12课_镜像修改器.blend`**。

> **目的**：把**镜像 + 倒角 + 简单形变**串成一个小完整作品，同时练"**一个镜像多份产出（X+Y）**"的思路。

## 六、常见坑（速查表）

| 坑 | 现象 | 正确做法 |
| ---------------------------------- | ---------------------- | ----------------------------------------- |
| **加了 Mirror 看不出变化** | 模型像是没动 | 原点在物体**正中心**，镜像重叠了。**先把原点挪到对称缝**（本课核心） |
| **镜像方向反了** | 对称到不对的那一侧 | 检查 **Axis** 勾的是 X / Y / Z 哪一条；对称缝方向错了就换轴 |
| **中间有一条缝/黑洞** | 左右两半接不上 | 勾上 **Clipping**（防穿模）+ **Merge**（合并重叠顶点，阈值 0.001～0.01） |
| **渲染时中缝闪烁/黑线** | 有两个面重叠打架 | 只勾 Clipping 没勾 **Merge**；补上 Merge |
| **镜像出来的半边是"死的"** | 想单独改却改不动 | 正常——它是修改器生成的，**要改就 `Apply` 后再编辑** |
| **Apply 完后悔了** | 参数没了、回不去 | **Apply 前先 `Ctrl+S` 存一份**或复制备份 |
| **缩放没应用，镜像距离不对** | 两边间隔不对、位置怪 | 先 **`Ctrl+A` → Scale 应用缩放**（呼应第 05、11 课铁律） |
| **接缝处不光滑/有折痕** | 细分后中缝一道棱 | 调整**修改器栈顺序**，让 **Mirror 在 Subdivision 之前** |
| **导出模型只有一半** | FBX/glTF 里少了一半 | 导出前**把 Mirror 修改器 Apply** |
| **在编辑模式找修改器面板** | 找不到 | 修改器是**物体级别**，回**物体模式**再加/改 |

## 七、下一课预告

**第 13 课：细分曲面（Subdivision Surface）**

今天你用**镜像修改器**学会了"**只做半边，另一半自动生成**"。下一课是**修改器家族里最出效果的一位**——**细分曲面**：它能把一个**方方的、面很少的方块**，**自动变得圆润光滑**，而且**你几乎不用手动加线**。做完头像、圆瓶、圆润产品的外壳，全靠它。它和今天的镜像经常**搭配出现**，栈顺序也常常是"Mirror 在上、Subdivision 在下"——**下一课见。**
