## 一、今日学习知识点

### 1. 从今天起，"建模"正式开始

前 7 课你学的全是"**怎么操作**"——怎么看、怎么转、怎么选、怎么切模式。今天开始进入"**怎么造东西**"。

而造东西的第一步永远是同一个动作：

> **`Shift + A` —— 在场景里"生成"一个东西。**

`Shift + A` 是 Blender 最常用的快捷键，没有之一。它的本质是"**添加（Add）**"，弹出的菜单叫 **Add 菜单**。

---

### 2. Add 菜单在哪、怎么用

`Shift + A` 会在**鼠标当前所在的位置**弹出菜单（不是屏幕中央，也不是世界原点）。菜单结构：

```
Mesh（网格）      ← 今天 90% 用这个
Curve（曲线）
Surface（曲面）
Metaball（融球）
Text（文字）
Volume（体积）
Grease Pencil（蜡笔）
Empty（空物体）   ← 后面第 34 课几何节点会用到
Image（图像）
Light（灯光）     ← 第 23 课布光用
Camera（相机）    ← 第 24 课用
```

今天只碰 **Mesh 子菜单**，但你现在就知道灯光和相机也从这里加，不用死记。

**子菜单展开方式**：鼠标悬停在 `Mesh` 上稍等，或直接往右划，展开第二级；再悬停 `Mesh → Circle` 之类带小三角的，展开第三级。

---

### 3. 八个基础几何体，各自是干什么的

这是今天的核心。**不要死背外貌，要背"它适合做什么"。** 选中会变蓝，敲回车 / 左键确认。

| 几何体            | 中文    | 外形本质        | **最适合拿它起手的模型**                  |
| -------------- | ----- | ----------- | ------------------------------- |
| **Plane**      | 平面    | 1 个四边形，零厚度  | 地面、地板、窗帘、布、贴着墙的标牌、贴参考图用         |
| **Cube**       | 立方体   | 6 个面，有长宽高   | **硬表面道具的万金油**：桌子、箱子、手机、建筑、电视、书本 |
| **Circle**     | 圆     | 一圈边，零厚度     | 用来做圆环截面、管道、需要手动拉出来的圆            |
| **UV Sphere**  | UV 球  | 经纬线划分的球     | 需要"规整经纬布线"的球：地球仪、眼球、灯罩          |
| **Ico Sphere** | 二十面体球 | 三角形均匀分布的球   | 更均匀的球：**雕刻起手**（第 32 课）、粒子、球状的树冠 |
| **Cylinder**   | 圆柱    | 顶底两个圆 + 侧面  | 杯子、盘子、笔筒、柱子、瓶身、轮子               |
| **Cone**       | 圆锥    | 一个圆底 + 收敛到尖 | 圆锥体、尖顶、喇叭、冰淇淋、树的雏形              |
| **Torus**      | 圆环    | 甜甜圈形状       | 甜甜圈、圆环、轮胎、管道转弯、把手的弯曲部分          |

> **一句话心法：不要从零一根点一根点地画，而是"找个最接近目标形状的基础体，先摆上去，再改"。**
>
> 新手最常见的错误是——想做一个杯子，从 `Plane` 开始拉点，拉到崩溃。正确做法是：**想到"杯子"→ 它是个旋转体，像圆柱 → 加一个 Cylinder → 然后挤出、收缩、做把手**。**基础几何体是"起手的坯料"，不是成品。**

---

### 4. 关键：添加时左下角的"操作面板"（Add 面板）

**这是今天最容易漏、也最值钱的一个点。**

`Shift+A` 加完一个几何体后，**屏幕左下角**会出现一个折叠面板（写着 `Add Cube` / `Add Cylinder` 之类），**只在这一刻有效**（一旦做了别的操作它就消失）。

点开它，你可以**立刻改这个几何体的生成参数**：

| 几何体            | 面板里能改什么                                     | 实战意义             |
| -------------- | ------------------------------------------- | ---------------- |
| Cube           | Size（边长）                                    | 直接定尺寸            |
| UV Sphere      | **Segments（经线数）**、**Rings（纬线数）**、Radius（半径） | **决定球的精细度**      |
| Ico Sphere     | **Subdivisions（细分数）**、Radius                | 细分越高越圆           |
| **Cylinder**   | **Vertices（顶点数）**、Radius、Depth（高）           | **决定圆的段数**（见下一节） |
| Cone           | Vertices、Radius1/2、Depth                    | 同上               |
| Torus          | **Major/Minor Segments（主/次段数）**、两个半径        | 决定圆环的圆滑度         |
| Plane / Circle | Size / Vertices、Radius、Fill Type            | 圆是空心（N-gon）还是带面  |

> **为什么重要？** 因为**在添加时就定好参数，比建模到一半再回去改省事 10 倍**。比如你要做一个"明显的低多边形（Low Poly）"风格的道具，加圆柱时直接把 `Vertices` 改成 6 或 8，它天生就是六边形柱，不用后期删面。

---

### 5. 段数（Vertices / Segments）到底该给多少？

这是新手天天纠结的问题。给你三条判断标准：

**① 默认的 32 段圆柱，圆吗？**  
Blender 默认圆柱 `Vertices = 32`。**32 段在日常生活中已经完全够用**——渲染出来肉眼基本看不出棱角，除非你给它打强光、做特写、或者镜头贴得很近。

**② 什么时候要减面（把 32 改成 8、12、16）？**

- 做 **Low Poly 风格**（低多边形风格，故意保留棱角的艺术效果）；
- 做**远处的小物件**（一个远景里的树、栅栏，32 段纯属浪费）；
- 做**六边形/八边形的柱体**（铅笔、蜂巢、nut 六角螺母）。

**③ 什么时候要加面（改成 48、64）？**

- 要做**镜头特写的大圆**（比如杯口、镜片），棱角会被看穿；
- 后面要接**光滑着色 / 细分曲面**，段数太低会显得僵硬。

> **模糊心法**：**远景 / 小物件 / 风格化 → 少段数；近距离 / 主角 / 写实 → 多段数。** 拿不准就先用 32，**不要一上来就追求"够不够圆"而疯狂加面**——面数爆炸是新手最常见的性能陷阱。

**随时可以改吗？** 可以。选中圆柱，进 `Tab` 编辑模式或直接在**右侧属性面板 → 绿色扳手图标（Object Data Properties）→ 图元数据**里，找到 `Vertices` 再改，它会**实时重建**（但会丢失你后来手动改的形变，所以还是"生成时定好"最稳）。

---

### 6. 重要区别：`Shift+A` 在**物体模式** vs **编辑模式**

同一组快捷键，在两个模式下干的**完全不是一回事**：

|              | 物体模式（Object Mode）       | 编辑模式（Edit Mode，`Tab` 后）                              |
| ------------ | ----------------------- | ---------------------------------------------------- |
| `Shift+A` 弹出 | 上面那一整个 Add 菜单（加**新物体**） | 一个**小得多的**菜单，只有 `Vertex / Edge / Face` 几项            |
| 作用           | 在场景里**新增一个独立的几何体**（新物体） | **在**当前这个网格**里，往内部加几何**（加点 / 加边 / 加面）——比如给一个面中间补一个顶点 |
| 结果           | 物体列表里多了一个新物体            | 物体数量不变，只是一个网格内部变复杂了                                  |

> **记法**：**物体模式的 `Shift+A` = 往场景里"搬进一个新东西"；编辑模式的 `Shift+A` = 往模型里"长出新的点线面"。**
>
> **重点：想加新几何体，一定先 `Tab` 退回物体模式！** 新手最常见的困惑是："我 `Shift+A` 怎么没反应 / 菜单怎么怪怪的"——99% 是因为你还停在编辑模式里。

---

### 7. 添加后几何体落在哪？——两个位置规律

- **位置**：新几何体生成在你**鼠标指针当前所在的位置**（3D 视图里的那个位置，不是屏幕坐标）。
- **朝向 / 轴向**：默认按世界坐标轴对齐。想让它**跟随视角**或**对齐全局面**，可以在 `N` 侧边栏的 `Tool` 里找 `Align` 选项，或加完后用第 03 课的 `R` 旋转调正。
- 加完想把它**归到世界原点**：`Shift+S → Selection to Cursor`（前提先把 3D 游标归零，见第 04 课）。

---

### 8. 心法：所有复杂模型，都是"基础体块搭出来的"

这是今天真正想让你带走的东西：

> **再复杂的模型，拆开看，都是一堆基础几何体的组合与变形。**

- 一把椅子 = 4 个掏细的长方体（腿）+ 1 个压扁的立方体（座）+ 1 个弯的长方体（靠背）；
- 一辆卡通小汽车 = 长方体车身 + 挖空的圆柱轮子 + 挤出前脸；
- 一个角色 = 球（头）+ 圆柱（脖子/四肢）+ 方块（躯干）。

**所以"建模快不快"，很大程度上取决于"你第一块砖选得对不对"。** 选对了起手形状，后面是顺水推舟；选错了，后面是跟软件较劲。今天这课练的就是"选砖"的眼力。

## 二、学习目标

学完本课你应该能：

1. 熟练用 `Shift+A` 添加任意一种基础几何体，并知道每种**最适合做什么**；
2. 在**添加瞬间**用左下角面板调好 `Vertices / Segments / Radius / Depth` 等参数量；
3. 根据"远景/特写、写实/风格化"判断段数该给多少，**不再无脑拉高面数**；
4. 清楚区分**物体模式**和**编辑模式**下 `Shift+A` 的不同含义，能自己排查"菜单不对"的问题；
5. 拿到一个具体物件（比如"台灯"），能**在动手前用一句话说出它由哪些基础几何体组成**。

## 三、实操练习任务

跟着做，全部在**物体模式**下开始。

**练习 1 · 认脸（5 分钟）**  
依次 `Shift+A → Mesh` 加上这 8 个：Cube、UV Sphere、Ico Sphere、Cylinder、Cone、Torus、Plane、Circle。每加一个，用第 02 课的方式绕它转一圈，**观察它们的布线（UV 球是经纬网、Ico 球是三角网）**。加完在右侧 `大纲视图`（Outliner）里数一数，是不是多了 8 个物体。练完全选 `A` → `X` 删掉，重来一遍。

**练习 2 · 亲手改参数量（8 分钟）**

1. `Shift+A` 加一个 **UV Sphere**，立刻点左下角 `Add UV Sphere`，把 `Segments` 从 32 改到 **8**、`Rings` 从 16 改到 **6** —— 观察它变成"橘瓣球"；
2. 再加一个 **Cylinder**，同样在左下角把 `Vertices` 改成 **6** —— 变成六棱柱；再改成 **3** —— 三棱柱；
3. 再加一个 **Torus**，把 `Major Segments` 调到 8 —— 变成一个多边形圈。  
   目的：**把"参数 → 外形"的关系亲手摸一遍。**

**练习 3 · 段数对比实验（7 分钟）**  
并排摆两个圆柱：一个 `Vertices = 8`，一个 `Vertices = 64`。给它们都加一个材质（随便什么色，第 21 课才细讲），然后**把相机推近看杯口那一圈**（按 `` ` `` 键可进相机视角，或用 `0` 键，参见第 02 课）。亲眼确认：**8 段在特写下有明显棱角，64 段几乎看不出**。这一步会让你真正理解"段数不是越多越好，是够用就好"。

**练习 4 · 模式对比（5 分钟）**  
选中一个立方体，`Tab` 进**编辑模式**，按 `Shift+A` —— 发现菜单只有 `Vertex / Edge / Face` 三项。按 `ESC` 关掉，`Tab` 回**物体模式**，再 `Shift+A` —— 完整 Add 菜单回来了。亲眼看过这一遍，以后就不会再"菜单不对"而懵。

**练习 5 · 用基础体搭一个"台灯"（10 分钟，纯堆砌，不建模）**  
只用 `Shift+A` 加基础几何体 + 用第 03 课的 `G / R / S` 调整，拼出一个台灯：

- 底座：`Shift+A` 加一个 **Cylinder**（`Vertices=32, Depth` 调小一点，压扁）；
- 灯杆：再加一个**细长的 Cylinder**（`Radius` 调小、`Depth` 调大），用 `G` + `Z` 挪到底座上面；
- 灯罩：加一个 **Cone**，`S` 缩放、`R` 旋转 180° 让它开口朝下，放到杆顶。

> **这一步不许进编辑模式、不许拉点。** 就靠"加体 + 移动 + 旋转 + 缩放"拼出轮廓。这是在训练你的"体块思维"——**先看会形状，再谈细节。**

## 五、课后小作业

1. **"砖料表"默写**：不看上面表格，写出 **Cube / UV Sphere / Ico Sphere / Cylinder / Cone / Torus / Plane / Circle** 八种几何体，各举 **1 个**最适合拿它起手的模型（一句话）。
2. **三件小物**：分别用最合适的基础几何体"起手"，搭出以下三样（同样只用加体 + `G/R/S`，先不建模）：
   - 一个**铅笔**（提示：几边形柱？为什么）；
   - 一个**甜甜圈**（提示：Torus 的两个段数分别控制什么）；
   - 一个**屋顶**（提示：Cone 的 `Vertices` 给多少才像四合院屋顶的方锥？）。
3. **段数判断题**：下面三种情况，圆柱 `Vertices` 你分别会给多少，为什么？
   - (a) 远景里的一排栅栏柱子；
   - (b) 镜头特写的马克杯杯口；
   - (c) 六角螺母。
4. **存档**：把今天的练习场景 `Ctrl+S` 存成 `第08课_基础几何体.blend`，放进你的 Blender 项目文件夹（第 07 课建立的规范）。**下一课要用这个文件继续。**

## 六、常见坑（提前避雷）

| 坑               | 现象                                        | 正确做法                                                                       |
| --------------- | ----------------------------------------- | -------------------------------------------------------------------------- |
| **编辑模式下加物体**    | `Shift+A` 菜单里只有 `Vertex/Edge/Face`，加不出新物体 | 先 `Tab` 回**物体模式**再加                                                        |
| **左下角面板消失**     | 加完想改参数，面板没了                               | 面板**只在刚添加、还没做任何其他操作时**有效；一旦动过，就去右侧属性面板的图元数据里改                              |
| **无脑拉高段数**      | 一个球给 256 段，场景卡顿                           | 按"远景/特写"给：默认 32 够用，特写才加，风格化要减                                              |
| **新物体跑到奇怪位置**   | 加出来的东西不在眼前                                | 它生成在**鼠标位置**；要么把鼠标移到想放的地方，要么加完用 `G` 挪，用 `Shift+S → Selection to Cursor` 归位 |
| **以为基础体不能改**    | 觉得加错了只能删掉重加                               | 生成后仍可在**图元数据**里改参数量，但**改参数会重置你后续的手动编辑**，所以关键参数最好"生成时就定"                    |
| **两个物体粘在一起分不开** | 加了新物体，编辑时却选中了旧物体                          | 每个 `Shift+A` 出来的都是**独立新物体**；用 `大纲视图` 或点击选中来区分，别和"编辑模式里加面"混淆                |

## 七、下一课预告

**第 09 课：挤出（Extrude）——`E`**

今天你学会了"摆砖"。下一课开始**把砖捏成形**：进入编辑模式，选中一个面，按 `E` 把它"挤"出来。这是 Blender 里**用出镜率最高的建模操作**——杯子从圆柱挤出杯壁、桌子从方块挤出四条腿、房子从盒子挤出屋顶……今天的"台灯"只要加上挤出，就能从"三块积木"变成真正的一个连体模型。**下一课见。**
