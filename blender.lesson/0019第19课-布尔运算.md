# 第 19 课 · 布尔运算 Boolean

> 阶段 3 · 布线 ｜ 学习时长建议：1.5～2 小时
> 前置：第 18 课 循环边与边流（已完成）
> 一句话定位：布尔是"用另一个物体当刀具，在本体上挖洞 / 焊接 / 取交集"的偷懒神器，但它留下的烂摊子要靠第 17、18 课的布线本事来收拾。

---

## 一、今日学习知识点

### 1. 布尔运算是什么
- 拿物体 B 当"运算对象"，对物体 A 做几何运算：挖掉、合并、只留重叠部分。
- 类比：饼干模具压面团——B 是模具，A 是面团。
- 在 Blender 里布尔是**修改器**（呼应第 12 课修改器概念）：非破坏性、可随时改运算对象位置、Apply 之后才落地。

### 2. 布尔三态（核心对照表）

| 模式 | 中文 | 效果 | 典型用途 |
|------|------|------|----------|
| Difference | 差集 | A 减去 B（B 覆盖的区域被挖掉） | 挖洞、开槽、开窗、抠字 |
| Union | 并集 | A 和 B 焊成一个整体 | 把两个零件焊接成一体 |
| Intersect | 交集 | 只保留 A、B 重叠的部分 | 取两物体的公共体积（较少用） |

### 3. 入口与参数
- 选中本体 A → 右侧**扳手图标** → Add Modifier → Generate → **Boolean**。
- 关键参数：
  - **Object**：点击吸管/下拉框，指定运算对象 B。
  - **Solver 解算器**：选 **Exact**（精确，默认推荐）；Fast 快但容易出破面，仅粗略预览时用。
- 运算对象 B 在视口里仍然可见会挡视线，记得隐藏它（见实操第 2 步的技巧）。

### 4. 布尔最大的代价：拓扑稀烂
- 布尔切出来的新边界是**直线硬切**，切完周围往往一片 **n-gon 和三角面**，循环边流全断。
- 这就是它放在阶段 3 讲的原因——**布尔产出的烂网格，正好用第 17 课（四边面）、第 18 课（边流）的本事来修**：
  - `K` 切刀把 n-gon 切成四边面；
  - `Ctrl+R` 环切重新布线；
  - `Ctrl+X` 融并多余循环边；
  - `G+G` 滑移调整边流走向。

### 5. 布尔 vs 手动布线的取舍（行业经验）
- **硬表面、平坦区域**：放心用布尔，又快又准（机箱开槽、旋钮孔、乐高凸点）。
- **要细分、要变形、曲率大的区域**：慎用布尔，手动布线更干净（角色、有机曲面）。
- 经验法则：**布尔负责"快"，布线负责"收"。**

### 6. Apply 的纪律
- 布尔是修改器，导出模型 / 进雕刻 / 某些后续编辑前必须 **Apply**。
- **Apply 之前先另存一个版本**（呼应第 07 课版本快照），Apply 不可逆。

## 二、学习目标

1. 能用 Boolean 修改器完成差集（挖洞）、并集（焊接）、交集三种运算。
2. 理解 Solver = Exact 的作用，知道法线反向会导致布尔结果诡异。
3. 养成"布尔完必收拾拓扑"的意识，能用第 17/18 课工具修复布尔后的网格。
4. 能判断一个造型该用布尔偷懒还是该手动布线。

## 三、实操练习任务

> 全程保持 `Ctrl+A` 应用缩放铁律（第 05 课）：布尔前把两个物体的缩放都 Apply 掉，否则运算尺寸对不上。

### 练习 1：方块挖洞（差集入门）
1. 新建场景：一个立方体 A（本体）+ 一个圆柱体 B（刀具，`Shift+A` → Mesh → Cylinder），圆柱竖着穿过立方体。
2. 选中立方体 A → 扳手 → Add Modifier → Boolean → Operation = **Difference** → Object 选圆柱 B → Solver = **Exact**。
3. 视口里立方体出现一个圆洞，但圆柱还挡着。选中圆柱 B → 物体属性（橙色方块图标）→ Visibility → 取消勾选 **Show in Viewports**（或用 `M` 移到单独集合并关闭），洞就露出来了。
4. 观察洞壁的拓扑：开线框叠加层，看洞口周围是不是一堆 n-gon/三角面。

### 练习 2：Union 焊接两个零件
1. 立方体 + 一个搭在它侧面的圆柱（做"旋钮凸台"）。
2. 立方体加 Boolean，Operation = **Union**，Object 选圆柱。
3. **Apply** 布尔修改器，进编辑模式 `L` 选中圆柱部分拖动 `G`——两者已经是连体的一个物体。
4. 对比：不用布尔直接 `Ctrl+J` 合并两个物体，内部其实是穿插的两套网格；Union 才是真正焊接。

### 练习 3：Intersect 交集体验（5 分钟）
1. 立方体和球体重叠一半。
2. 立方体加 Boolean → **Intersect** → 只留下重叠的"杏仁形"体积。知道这个模式存在即可。

### 练习 4：布尔后修拓扑（本课主菜）
1. 回到练习 1 的带洞立方体，**先另存版本**，再 Apply 布尔。
2. 进编辑模式观察：洞口周围 n-gon 遍地、边流全断。
3. 用第 17/18 课的本事收拾：
   - `K` 切刀从洞口边缘向立方体四角引线，把大 n-gon 拆成四边面；
   - `Ctrl+R` 沿洞壁环切一圈，让洞口有一圈干净的循环边（方便后续倒角）；
   - `G+G` 滑移调整洞口周边边的疏密。
4. 修好以后加 `Ctrl+2` 细分对比：修之前加细分会塌陷起皱，修之后洞口圆润挺括——**这就是布线课存在的意义**。

### 练习 5：法线反向踩坑练习
1. 复制一个圆柱，进编辑模式全选 → `Alt+N` → Flip 翻转法线。
2. 用它对立方体做 Difference，观察结果诡异（洞不对或整个消失）。
3. 开启 Face Orientation 叠加层确认红色，框选该物体 → `Shift+N` 重算外侧法线，布尔恢复正常。**以后布尔结果离奇，先查法线。**

## 五、课后小作业

**做一个"迷你插座面板"：**
1. 立方体压扁做面板主体；
2. 用布尔差集挖出两个或三个插孔（扁立方体当刀具，孔壁要有厚度感）；
3. Apply 后修复每个孔周围的拓扑，让孔边缘有一圈干净循环边；
4. 孔边缘 `Ctrl+B` 小倒角收边（呼应第 11 课）；
5. 面板四角用布尔或环切做出螺丝孔位。

验收标准：加 `Ctrl+2` 细分后孔洞不变形、面板表面不起皱。做完另存为 `插座面板_v1.blend`。

## 六、常见坑

1. **加完布尔没反应**：多半是 Object 没指定对，或运算对象和本体根本没相交。
2. **运算对象挡住视线**：布尔修改器不会自动隐藏刀具，记得手动隐藏 B（练习 1 第 3 步）。
3. **布尔结果诡异/破洞/消失**：先查法线（Face Orientation 红色 = 反面），`Shift+N` 修复。
4. **Exact 报错或结果残缺**：两个物体有恰好共面的重叠面（面贴面零厚度重叠），把刀具稍微挪一点避开共面。
5. **缩放没 Apply 就布尔**：运算尺寸对不上，坑位偏移——老规矩 `Ctrl+A` → Scale。
6. **布尔后忘记修拓扑**：一时爽，后面加细分、倒角、展 UV 全部连环翻车。
7. **曲面/要变形的部位滥用布尔**：角色脸、布料这类地方布尔完布线没法救，老实手排。
8. **没另存就 Apply**：布尔不可逆，Apply 前先存版本。
