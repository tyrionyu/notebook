## 一、今日学习知识点

### 1. 核心思维：你只是在"搬摄像机看"，没有在搬物体

新手最大的误会，是以为"我想从侧面看立方体，得把立方体转过来"。

**真相是**：Blender 里你永远不动物体，你动的是**你看它的那只眼睛**（视口摄像机）。

- 转的是"眼睛"，不是物体 → 所以物体位置、坐标一个都没变；
- 判断标准：操作后看左下角坐标数值有没有变。没变 = 你只是换了视角（对的）。

> 记住这句话，后面 33 课都不会再犯"我把模型转歪了"的错。

### 2. 鼠标三件套（最高频，必须先练熟）

| 操作              | 手法                              | 效果          |
| --------------- | ------------------------------- | ----------- |
| **旋转视图（Orbit）** | 按住**鼠标中键**拖动                   | 绕物体转圈看      |
| **平移视图（Pan）**   | `Shift` + 按住**鼠标中键**拖动          | 画面整体上下左右推   |
| **缩放视图（Zoom）**  | 滚动**滚轮**                        | 拉近拉远        |
| **精细缩放**        | `Ctrl` + 按住**鼠标中键**拖动           | 慢速缩放，微调用    |

> 如果你的鼠标没有中键（或中键很难按）：`Edit → Preferences → Input → Emulate 3 Button Mouse` 勾上，之后用 `Alt` + 左键 代替中键。

### 3. 正交视图：一键跳到标准视角（数字小键盘）

| 快捷键            | 视角          |
| -------------- | ----------- |
| **Numpad 1**   | 前视图（Front）  |
| **Numpad 3**   | 右视图（Right）  |
| **Numpad 7**   | 顶视图（Top）    |
| `Ctrl` + 上面三个 | 反向视图（后/左/底） |
| **Numpad 5**   | 在**透视**和**正交**之间切换 |
| **Numpad 0**   | 切到**相机视角**（Camera View） |

> `Numpad = 数字小键盘`（键盘右侧那一块），不是主键盘上方的数字排。

### 4. 透视 vs 正交 —— 一个必须搞懂的区别

- **透视（Perspective）**：像人眼看东西，近大远小，有纵深感。日常看模型用这个。
- **正交（Orthographic）**：没有近大远小，平行线永远平行。**做精确对齐、检查比例时用这个**，因为尺寸不会被透视"骗"歪。

在 Engineering / 硬表面建模里，老手习惯按 `Numpad 5` 切到正交来对齐，再切回透视看效果。

### 5. 把东西"拉回眼前"：聚焦与取景

| 快捷键                | 作用                             |
| ------------------ | ------------------------------ |
| **Numpad `.`（小数点）** | 聚焦到**当前选中的物体**（最常用！）           |
| **Home 键**          | 显示场景**所有物体**（Frame All）        |
| **Numpad `/`（斜杠）** | 进入**局部视图**，只显示选中物体；再按一次退出      |

> 场景越做越大后，"按 Numpad `.` 找不到东西"是新手第一大痛点，这一组快捷键能救你。

### 6. 用小键盘微调视角

- `Numpad 4 / 6`：视角向左 / 向右转一点
- `Numpad 8 / 2`：视角向上 / 向下转一点
- `Numpad 9`：视角上下翻转 180°

### 7. 变换特定视角（View → Align View）

菜单 `View（视图）→ Align View（对齐视图）` 里有一堆"让某个轴朝向自己"的选项，最高频的三个是：

- `Shift + Numpad 1`：**前**视图并**锁定**（此后转不动，只能平移缩放）
- `Shift + Numpad 3`：**右**视图并锁定
- `Shift + Numpad 7`：**顶**视图并锁定

> 锁定后要回到自由旋转：`View → Align View → Align to World View`，或按 `Numpad 5` 附近任意自由视角快捷键。

### 8. 没有小键盘的笔记本怎么办

1. `Edit → Preferences → Input → Emulate Numpad` 勾上 → 主键盘上方的数字键就能当小键盘用（但会占用 1~9 的部分功能键，取舍看你）；
2. 或者用视口**右上角的导航轴球**（Navigation Gizmo），点轴上的小球/圆环直接跳视角；
3. 或者 `View` 菜单里逐条点。

### 9. 附赠：视图切换与着色无关

注意区分两件事：
- **视角**（看的方向）—— 本课内容；
- **着色模式**（线框/实体/材质预览/渲染预览）—— 第 01 课右上角四个小球。

两者独立，可以"顶视图 + 材质预览"任意组合。

学完本课，你应当能够：

- [ ] 用 `Numpad /` 进入局部视图并退出；
- [ ] 遇到"东西不见了"，能独立用三种方法把视图拉回来。

## 三、实操练习任务

> 全程不建任何模型，只练"眼睛的功夫"。做错按 `Ctrl+Z` 或不做也没损失。

1. **热身：转一圈**  
   打开 Blender（默认有立方体）。按住**中键**慢慢转一圈，感受"物体没动、视角在动"。
2. **平移与缩放**  
   用 `Shift + 中键` 把画面推来推去；滚轮放大到只剩立方体一角，再缩小看全局。
3. **跳标准视角**  
   依次按 `Numpad 1`（前）、`Numpad 3`（右）、`Numpad 7`（顶），每按一个看一下立方体形状变化。再按 `Ctrl+1 / Ctrl+3 / Ctrl+7` 看反面。
4. **透视 ↔ 正交**  
   按 `Numpad 5`，观察立方体从"有纵深"变成"方正平面"；再按一次切回。
5. **聚焦练习（重点）**  
   ① `Shift+A → Mesh → UV Sphere` 加个球；② 用 `G` 把它挪到很远；
   ③ 选中它，按 `Numpad .` —— 视图瞬间飞过去。这就是以后救命的那一下。
6. **局部视图**  
   选中球，按 `Numpad /`，场景只剩球；再按一次，立方体回来了。
7. **锁定视角**  
   按 `Shift + Numpad 1`，试着用中键转 —— 你会发现转不动（被锁在前视图）。再从 `View → Align View → Align to World View` 恢复自由。
8. **相机视角初体验**  
   按 `Numpad 0` 进入相机视角，界面多出一个取景框；再按 `Numpad 0` 退出。（相机细节留到第 24 课。）
9. **无小键盘适配（可选）**  
   如果你用笔记本，去 `Preferences → Input` 勾上 `Emulate Numpad`，重做第 3 步。

## 六、小提示与常见坑

- **坑 1：以为转视角 = 转物体。** 只有当左下角坐标数值变了，或物体在 Outliner 里被旋转属性改变，才算真转了物体。
- **坑 2：找不回默认视角。** 按 `Home` 显示全场景，或 `View → Align View → Align to World View`，基本都能救。
- **坑 3：Numpad 在小键盘上，不是主键盘数字排。** 笔记本用户先勾 `Emulate Numpad`，别硬按到崩溃。
- **坑 4：`Numpad 5` 后以为自己坏了。** 那只是"透视/正交"切换，不是故障。
- **坑 5：锁定视角后转不动。** 是你按了 `Shift + Numpad 1/3/7` 把视角锁死了，不是软件卡住。
- **手感提示**：鼠标三件套前三天会觉得别扭，正常。到第 3 课开始做位移操作时，你才会真正体会到这一课的价值。
