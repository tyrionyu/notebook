## 一、今日学习知识点

### 1. 今天你学会"让方块变圆"的魔法

昨天你用**镜像修改器**，让"只做半边"变成现实。今天这位，是**修改器家族里最出效果的一位**：

> **一句话理解**：细分曲面 = **给模型挂上一个"自动磨圆模块"，它把每个面自动切成更小的面，并把新顶点往里"收缩"，让棱角融化、表面变圆润光滑。**

**打个比方**：你手里有一个**用纸折出来的方块盒子**——棱是硬的、面是平的。细分曲面就像**给这个纸盒吹了口气，让它慢慢鼓起来变成圆润的充气枕**。**你一个顶点都没手动加，它自己就圆了。**

**它和昨天那个镜像是什么关系？** 都是修改器——**非破坏性、可堆叠、要 Apply 才落地**（第 12 课那四条特性，今天完全通用）。区别在于：镜像管"**复制对称**"，细分管"**磨圆平滑**"。

---

### 2. 最快入口：`Ctrl + 1 / 2 / 3`（先记这个）

上节课加 Mirror 是走菜单（扳手 → Add Modifier → Generate → Mirror）。细分曲面**有个超快的键盘方式**，你会发现老手一直在用：

```
选中物体（物体模式）→ 直接按 Ctrl + 1 → 瞬间加了 1 级细分
                        Ctrl + 2 → 2 级细分
                        Ctrl + 3 → 3 级细分
```

> **注意**：这里的数字键要按**主键盘上方那排数字**，不是小键盘。`Ctrl+1` 给的是"**视口级别 = 1 级**"。

**如果快捷方式没反应**，走正规入口也行：

```
右侧属性面板 → 【蓝色扳手图标（Modifier）】→ Add Modifier → Generate（生成）→ Subdivision Surface
```

加完后，修改器卡片下方的两个数值才是真正要理解的东西（下一节）。

---

### 3. 核心参数：Viewport Levels 和 Render Levels，别搞混

细分曲面面板里有**两个长得几乎一样的数值**，新手 90% 会在这一栏懵一次：

| 参数 | 管什么 | 通俗解释 |
| ---------------------- | ------------------------------ | ------------------------------------ |
| **Viewport Levels（视口）** | 你在视口里**看到的**平滑程度 | 调它让"屏幕里看着圆"，不影响出图 |
| **Render Levels（渲染）** | 你**渲染出图时的**平滑程度 | 决定最终成片的圆滑度，可以调更高 |

> **一句话记住**：**Viewport 管"你干活时顺不顺手"，Render 管"最后照片圆不圆"。**

**为什么要分成两个？** 因为细分级数是**指数级涨面**的——1 级 = 每个面切成 4 份，2 级 = 16 份，3 级 = 64 份。级别一高，视口操作会卡。所以：

- **干活阶段**：Viewport 给 **1～2 级**，够看形状、又跟手；
- **渲染阶段**：Render 给 **3～4 级**，让出图足够圆润；
- **常用配置**：Viewport 2 / Render 3 是很多人的默认习惯。

> **坑**：如果你发现"**视口看着挺好的，一渲染反而变形了**"——八成是**两个数值差太多或者填反了**，先回来核对这一栏。

---

### 4. 它到底怎么"变圆"的？（30 秒底层逻辑）

不用深挖数学，但**知道原理，你才知道怎么控制它**：

1. 细分曲面默认用的算法叫 **Catmull-Clark**（记住名字就够了，不用手算）；
2. 它做的事：**把每一个面拆成更小的面，然后把新产生的顶点往里"收"一点**；
3. 反复做这件事，**棱角就被越磨越圆**——所以级数越高越圆滑。

**最关键的一句（本课的灵魂）：**

> **细分出来的形状，是被你原模型的"边"和"面"的结构决定的。**
>
> 换句话说：**细分不改你的布线，它只是"放大"你布线的好坏。**

- 你用**一个方块**去细分 → 它变成**一个圆溜溜的球/枕头**；
- 你在方块上**靠近边缘切一圈环切** → 细分后，**靠近边缘的地方会保留更明显的棱角**（因为边挤在一起了）；
- 你用**三角面 / n-gon（多边面）** 去细分 → 就会**起皱、出现拉丝、怪褶子**。

> **这就是为什么"布线"重要**（第 17 课会正式讲）。**今天先埋下这颗种子：想要细分漂亮，原模型尽量保持"四边面"。**

---

### 5. 行业思路：低模 + 细分 = 高模

这是细分曲面真正厉害的地方，也是它成为**几乎所有建模流程标配**的原因：

> **你不必"手动雕出几十万个面"，而是"搭一个干净的低面数骨架，再让细分一口气把它变高面数、变圆润"。**

- **低模（Low Poly）**：面少、操控快、改形状方便——**用来定形**；
- **细分**：一键变高模、圆润——**用来出效果**；
- **好处**：改形状时只动低模（几个点的事），效果却是高模的——**改动成本极低**。

**这就是新手和进阶玩家的分水岭**：新手一个面一个面地拉圆；进阶玩家搭个方骨架，按 `Ctrl+2`，完事。

---

### 6. 想保留硬边？用 Crease（折痕）

细分把所有棱都磨圆，可有时候你要**"圆中有硬"**——比如一个圆润的手机壳，但四角要挺括；或一个杯口要有点厚实的边。

**解决办法：给特定的边加 `Crease`（折痕）。**

```
进入编辑模式 → 选边层级（按 2）→ 选中要"变硬"的边
→ 快捷键 Shift + E → 拖动鼠标（或直接输入数值）
→ 数值越大（1 是满值），那条边在细分后越"硬"、越不容易被磨圆
```

- `Shift+E` 设值后，可以用 **`Shift+E` → 输入 0** 或菜单 `Edge → Clear Crease` 清除；
- 也可以在 **N 面板（右侧按 `N`）→ Item → Edge Data → Crease** 里看和改数值。

> **一句话记住**：**Crease = 在"自动磨圆"的世界里，保住那几条你想留的硬边。**

---

### 7. 和 Mirror 搭配：栈顺序又来了（复盘上节课）

上节课你学到一个意识：**修改器从上往下依次执行（修改器栈）**。今天细分和镜像经常一起出现，顺序很讲究：

| 栈顺序 | 效果 |
| ------------------------------ | ---------------------------------------------- |
| **Mirror 在上 → Subdivision 在下** | 先对称、再磨圆，**中间接缝更干净**（推荐） |
| **Subdivision 在上 → Mirror 在下** | 先磨圆、再镜像，**接缝处容易一道硬折痕** |

> **结论照旧**：**Mirror 放最上，Subdivision 跟它后面。** 上节课练习 4 你已经见过这个现象，今天算是"正式用法"。

**操作**：拖修改器卡片右上角的**十字手柄**上下调顺序；点**小眼睛**开关；点**小叉**删除。

学完本课你应该能：

6. 知道**低模 + 细分 = 高模**这条行业思路，能靠"搭低模 + 按 Ctrl+2"快速出圆润造型；
7. 会正确处理 **Mirror 与 Subdivision 的栈顺序**（Mirror 在上）。

## 三、实操练习任务

### 练习 1 · 第一次按下 `Ctrl + 2`（5 分钟）

**先感受"一键变圆"的震撼。**

1. `Shift+A` 加一个 **Cube**（物体模式选中它）；
2. 直接按 **`Ctrl + 2`** → **看结果**：方块瞬间变成一个**圆滚滚的软糖/枕头**；
3. 按 **`Ctrl + 1`** → 变圆程度变浅一点；**`Ctrl + 3`** → 更圆更光滑（同时观察**面数猛涨、视口有没有变卡**）；
4. 打开右侧**扳手面板**，找到刚加上的 **Subdivision Surface** 卡片，把 **Viewport Levels** 和 **Render Levels** 分别改成不同数字，观察视口变化（改 Render Levels 视口**不变**——因为它只管出图）。

> **目的**：把"`Ctrl+数字` = 一键加细分"变成条件反射。同时第一次亲眼看到 Viewport / Render 两个数值的分工。

---

### 练习 2 · 不同"起手形状"被细分后会变成什么？（10 分钟）

**这是理解"细分=放大布线"的关键练习。**

逐个试，每个都按 `Ctrl+2`，**边试边记结果**：

1. **Cube** → 变成**圆润的球状/软糖**；
2. **Cylinder（圆柱）** → 变成**两头圆鼓的胶囊/药丸**（因为顶盖的平面被磨圆了）；
3. **Cone（圆锥）** → 变成**像个圆润的水滴/飞弹头**；
4. **Plane（平面）** → 因为是单个平面，细分后**还是平的**（没有体积可收缩）；
5. **UV Sphere / Ico Sphere** → 更圆，但注意 **Ico Sphere（三角形拼的球）细分后可能出现乱的褶子**——这正是"三角面不适合细分"的直观证据。

> **目的**：亲眼建立"**原始结构决定细分结果**"的直觉。为第 17 课布线打地基。

---

### 练习 3 · 环切改变细分结果：方块 → 圆角方块（15 分钟 · 主菜）

**这是今天最重要的练习：学会用"加线"来控制细分后的圆角大小。**

1. `Shift+A` 加 **Cube** → 按 `Ctrl+2` → 得到圆滚滚的软糖；
2. 撤销回方块 → 进**编辑模式** → `Ctrl+R` **环切**：在**每个方向靠近边缘处各切一圈**（上下一圈、左右一圈，让每个面被分成"中间大格 + 四边窄条"）；
   - 提示：`Ctrl+R` 悬停预览黄线 → **滚轮调条数** → 左键确认 → **右键让切口居中**或左键定下；
3. 回物体模式 → `Ctrl+2` → **看结果**：现在不再是软糖，而是变成**一个四角带漂亮圆角的方块**（像骰子/圆角盒子）；
4. **规律总结**：**你越靠近边缘切环切、"边挤得越密"，细分后那个位置的圆角就越小、棱就越挺**；
5. 再试一次：把环切**切在更靠近边缘的地方** → 圆角更小；**切在中间** → 圆角更大。

> **目的**：理解**"布线控制细分"**这条核心逻辑——**你想让哪里圆、哪里硬，靠切线的位置说了算。**

---

### 练习 4 · `Shift+E` Crease：让细分保留硬边（8 分钟）

1. 拿练习 1 的软糖方块 → 进**编辑模式** → 按 **`2`** 切到**边层级**；
2. **`Alt+左键`** 选中**顶面四周的 4 条边**（循环边选择，第 06 课学过）；
3. 按 **`Shift + E`** → 拖动鼠标往上 → **输入 `1`**（满折痕）；
4. 回物体模式（Tab）→ 观察：**顶面边缘从圆润变成了明显的硬边**，而侧面依然是圆的；
5. 再回去把 Crease 改成 **`0.5`** → 对比：半硬半圆；改成 **`0`** → 恢复全圆。

> **目的**：掌握 **Crease = 在细分世界里保留硬边**。做"圆润但有棱角"的产品外壳时，这一招极常用。

---

### 练习 5 · 综合小作品：一个"圆润马克杯"（12 分钟）

把今天学的东西串起来：

1. `Shift+A` 加 **Cylinder** → 编辑模式 → 把顶面选中 → `E` 挤出，做出**杯身**（或用 `Ctrl+R` 环切后调点，拉出杯子的腰线）；
2. 按 **`Ctrl+A` → Scale 应用缩放**（**铁律，回收第 05 / 11 课**——缩放没应用的话，细分和厚度都会不均匀）；
3. 加 **Subdivision Surface**（`Ctrl+2`）→ 杯子瞬间**圆润成型**；
4. 如果杯口太圆、你想让它**挺一点** → 选中杯口循环边 → `Shift+E` → 输入 `0.7` 左右，让它保留一点硬度；
5. **加个把手**（选做）：`Shift+A` 加 Torus（圆环）→ 缩小 → 挪到杯侧 → 也给个细分；
6. **栈顺序练习**：如果你用了镜像做对称把手，记牢 **Mirror 在上、Subdivision 在下**；
7. `Z` 切渲染预览看一眼 → **`Ctrl+S` 存成 `第13课_细分曲面.blend`**。

> **目的**：完整走一遍"**搭低模 → 加细分 → 需要时用 Crease 保硬边**"，这是几乎所有圆润造型产品的通用套路。

## 六、常见坑（速查表）

| 坑 | 现象 | 正确做法 |
| ---------------------------------- | ---------------------------------- | ------------------------------------------ |
| **按 `Ctrl+数字` 没反应** | 什么都没发生 | 确认在**物体模式**、且**物体是选中的**；数字键用**主键盘上排**，不是小键盘 |
| **视口看着圆、渲染却变形/不一样** | 出图和屏幕不一致 | 检查 **Viewport Levels 和 Render Levels** 是否填反或差距过大 |
| **细分后起皱、拉丝、怪褶子** | 表面出现乱纹 | 原模型有**三角面 / n-gon（多边面）**。**尽量改成四边面**，或改用别的方式（第 17 课详讲） |
| **细分后面数暴涨、视口很卡** | 操作一顿一顿 | **降低 Viewport Levels**（1～2），保留 Render 高层级 |
| **加了细分却变形拉长** | 形状歪、厚度不均 | **缩放没应用**！先 **`Ctrl+A` → Scale**（呼应第 05 / 11 课铁律） |
| **细分把棱角全磨没了** | 想要硬边却圆了 | 用 **`Shift+E` 给边加 Crease**，或**靠近边缘环切**把边挤密 |
| **接缝处一道硬折痕** | 对称物体中间不平滑 | **修改器栈顺序错**：让 **Mirror 在上、Subdivision 在下** |
| **镜像+细分后导出少一半/仍是低模** | FBX / glTF 里不对 | 导出前把修改器 **Apply**（第 12 课知识，Apply 前先存盘） |
| **在编辑模式里找细分面板** | 找不到 | 修改器是**物体级别**，回**物体模式**加/改 |
| **`Ctrl+数字` 改不动已加好的级别** | 按了没变化 | 快捷方式只在**没有细分修改器时**新建；已有的话直接去**扳手面板改数值** |

**第 14 课：阵列修改器（Array Modifier）**

今天你用**细分曲面**，把"**方方的低模**"一键变成了**圆润光滑的高模**——你掌握了建模里"出效果"最常用的一招。下一课是**修改器家族里的"复制机器"**——**阵列修改器**：它能把一个物体**自动复制成一整排、一整圈、一大片**，做**栏杆、楼梯、齿轮、路面砖块、螺旋阵列**全靠它。它也会用到今天讲的**修改器栈顺序**意识，还会和**偏移量、相对偏移**这些参数打交道——**下一课见。**
