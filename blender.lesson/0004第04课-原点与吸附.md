## 一、今日学习知识点

### 1. 什么是"原点"（Origin）

每个物体身上都有一个**原点**——就是那个**橙红色的小圆点**（选中物体时能看见，也被叫作 Pivot / 物体中心点）。

- 它不是一个"点"，而是一套**坐标系的原点**：物体的位置（Location）说的就是"原点在世界坐标的哪里"；
- 缩放、旋转**默认都绕着原点转**；
- 修改器（Mirror、Array 等）也**默认以原点为基准**。

> 一句话记住：**原点 = 物体的"把柄 + 旋转轴心 + 一切操作的基准点"。**

**在哪看？** 按 `N` 打开右侧 Item 面板，最上面的 Location / Rotation / Scale 就是**原点**的属性，不是模型本体的属性。

### 2. 为什么"明明摆正了，一缩放就偏"

新手最常见的崩溃场景：一个杯子模型，看起来在桌面上，`S` 一放大，它整个**沉到桌子底下去**了。

原因：这个模型的**原点不在底部**，而在几何中心（或别的怪地方）。放大是"以原点为中心撑开"，原点偏上，模型下半部分自然往下去。

**结论：做道具、做产品模型时，养成习惯把原点调到模型的"底部中心 / 对称轴"上。** 这是包装建模（盒子、瓶罐）能对得齐的关键。

### 3. 怎么改原点：`Object → Set Origin`（快捷键 `Shift+Ctrl+Alt+C`）

回视口顶部菜单栏：`Object（物体）→ Set Origin（设置原点）`，里面有四五个选项：

| 选项 | 作用 | 典型用途 |
| --- | --- | --- |
| **Origin to Geometry** | 原点移到模型**几何中心**（体积中心） | 想让物体"绕自己中心转/缩放" |
| **Origin to Geometry (Media Point)** | 移到所有顶点的**平均位置** | 形状不规则时更稳 |
| **Origin to 3D Cursor** | 原点挪到 **3D 游标**的位置 | **最常用**——想把原点精确放到某处 |
| **Origin to Center of Mass** | 移到物理质心 | 做物理模拟时 |
| **Origin to Bottom / 等等** | 部分版本有"到底部"选项 | 让模型"站在地面上" |

> 版本差异提醒：Blender 3.x / 4.x 里这个菜单在 `Object → Set Origin`；快捷键 `Shift+Ctrl+Alt+C` 不一定所有版本都生效，**菜单点最稳**。

**改原点的标准流程（重要，背下来）：**

```
1. 先放好 3D 游标（游标 = 你要放原点的位置）
2. 选中物体
3. Object → Set Origin → Origin to 3D Cursor
4. 完事，原点就"钉"在你要的位置了
```

### 4. 3D 游标（3D Cursor）：红白相间的那个小十字

就是场景里那个**红白相间的小圈 + 十字**（第 3 课 Pivot 里的 3D Cursor 说的就是它）。

它的用法：
- **`Shift + 右键`** 点任意位置 → 游标瞬移到那个点；
- **`Shift + C`** → 游标回到世界原点（0,0,0）并重置视图；
- **`Shift + S`** 打开吸附菜单，可以把游标吸到别的东西上（下面第 5 点讲）。

**游标的三大用途：**
1. 当作"原点搬运工"——`Object → Set Origin → Origin to 3D Cursor`；
2. 当作"旋转/缩放中心"——Pivot 切到 `3D Cursor`，物体就绕游标转（第 3 课讲过）；
3. 当作"新建物体的出生地"——新建的立方体/球体，都出生在游标位置。

### 5. `Shift + S`：吸附菜单（Snap，本课核心）

选中物体后按 **`Shift + S`**，会弹出一个**饼状菜单**（Pie Menu），里面全是"把 A 吸到 B"：

**游标区（Cursor to ...）—— 把游标吸过去：**

| 选项 | 作用 |
| --- | --- |
| **Cursor to World Origin** | 游标回 (0,0,0) |
| **Cursor to Selected** | 游标吸到**选中物体**的位置（**超常用**） |
| **Cursor to Active** | 游标吸到**最后选中的那个**物体 |
| **Cursor to Grid** | 游标吸到最近网格点 |

**选中对象区（Selection to ...）—— 把物体吸过去：**

| 选项 | 作用 |
| --- | --- |
| **Selection to Grid** | 选中的物体**对齐到网格**（整数坐标） |
| **Selection to Cursor** | 物体**移动到游标**（**超常用**） |
| **Selection to Cursor (Keep Offset)** | 物体移动到游标，但**保持相对位置**（多个物体一起搬时用） |
| **Selection to Active** | 其他物体吸到最后选中的那个上 |

**黄金组合（今天就练这个）：**
> 选中 A → `Shift+S` → `Cursor to Selected` → 选中 B → `Shift+S` → `Selection to Cursor`
> **效果：B 精确地站到 A 的位置上。** 这就是"对齐两个物体"的正规做法。

### 6. 实时拖拽吸附：`Shift` 键

拖动的时候想"卡"到网格/顶点上，不用每次按 `Shift+S`：

| 操作 | 效果 |
| --- | --- |
| **按 `G` 之后 + 按住 `Shift`**（鼠标不放） | 物体在网格点上**一格一格跳** |
| 视口顶部那个**磁铁图标**（或 `Shift+Tab` 切换） | 打开**全局吸附**模式 |

**磁铁图标的吸附目标（点磁铁右边的小下拉箭头）：**

- **Increment（增量）**：默认，按网格/角度增量吸附（最常用）；
- **Vertex（顶点）**：吸附到别的物体的**顶点**上；
- **Edge（边）**：吸附到**边**上；
- **Face（面）**：吸附到**面**上；
- **Volume（体积）**：吸附到体积内部。

> 打开磁铁（`Shift+Tab`）后，配合 **`Shift+S` 菜单没提的** 一个钩子：在顶部吸附设置里可以勾 **"绝对网格对齐"**，让物体永远落在网格线上——做包装盒的六个面时非常省事。

### 7. 网格单位与"对齐"的关系

Blender 默认 **1 单位 = 1 米**，视口里的网格通常是 **1 格 = 1 米**（放大看会细分到 0.1）。

- `Shift+S → Selection to Grid` → 把坐标**取整**到最近的网格线；
- 做包装设计想按毫米算：`Scene Properties（场景属性）→ Units → Unit System 改成 Millimeters`。

> 记住：**"吸附"本质是"把坐标取整/对齐到某个参照物"**。想清楚参照物是谁，就不会乱。

## 三、实操练习任务

> 全程用默认立方体 + 一个 UV 球，重点是**把"对齐"这件事从手感变工程**。

**1. 看见原点**
- 选中立方体 → 按 `N` → 看 Location 的 (0,0,0)，说明原点在世界原点；
- 按 `Ctrl+A → All Transforms`（应用全部变换）→ 原点回到几何中心，观察橙点位置变化。

**2. 复现"缩放跑偏"（体会痛点）**
- 放大视图，加一个 UV 球（`Shift+A → Mesh → UV Sphere`）；
- 按 `G` `Z` `0.5` 把它抬高一点；
- 切 Pivot（第 3 课的小圆点图标）到 **3D Cursor**（游标在 0,0,0）→ 按 `S` 放大 → 球**往下沉**了；
- 把 Pivot 切回 **Median Point** → 再 `S` → 球绕自己中心放大。
- 追问自己：**是球变了，还是我缩放的中心变了？**（答案：缩放中心变了。）

**3. 移动 3D 游标（核心手活）**
- 在视口里 `Shift + 右键` 点几下，看游标满场乱飞；
- 按 `Shift + C` → 游标干净地回到 (0,0,0)；
- 再 `Shift+右键` 点地面某个位置，准备下一步用。

**4. 把原点搬到游标上（重点）**
- 选中立方体 → `Object → Set Origin → Origin to 3D Cursor`；
- 观察：橙点**跳**到你刚点的游标位置了，但立方体本体没动；
- 现在按 `S` 缩放 → 立方体**绕着新原点**缩放，位置明显偏移 —— 这就是"跑偏"的原理演示。

**5. 让原点"回到自己身上"**
- `Object → Set Origin → Origin to Geometry` → 原点回到立方体中心；
- 顺手把立方体的原点调到**底面中心**（做道具必备）：
  1. 进编辑模式 `Tab` → 选中底面 4 个顶点 → `Shift+S → Cursor to Selected` → 回物体模式 `Tab`；
  2. `Object → Set Origin → Origin to 3D Cursor` → 原点到"底面中心"；
  3. 试着 `S` 缩放/`R` 旋转，看它是不是"站在地面上转"了。

**6. 两物对齐：`Shift+S` 黄金组合（今天最值钱的一步）**
- `Shift+A` 再加一个立方体 B；
- `G` `X` `4` → 把 B 挪到右边；
- 选中 A → `Shift+S` → **Cursor to Selected**；
- 选中 B → `Shift+S` → **Selection to Cursor**；
- 结果：**B 精确地叠到 A 身上**。反复做 3 遍，形成肌肉记忆。

**7. 多物体整体搬家**
- 选中 A、B（`Shift` 分别点）→ `Shift+S` → **Selection to Cursor (Keep Offset)**；
- 观察：两个物体一起移到游标，但**彼此间距不变**。

**8. 对齐到网格**
- 把物体随手拖到一个"非整数"的位置（比如 X=1.37）；
- `Shift+S → Selection to Grid` → 看它"啪"地跳到整数网格线上。

**9. 磁铁吸附**
- 按 `Shift+Tab` 打开顶部磁铁；
- 按 `G` 拖动物体 → 它会**一格一格跳**（增量吸附）；
- 把吸附目标改成 **Vertex**，拖着 A 靠近 B 的角 → 会自动"咔"到 B 的顶点上；
- 练完 `Shift+Tab` 关掉磁铁（**新手别一直开着**，容易误吸）。

**10. 挑战：搭一个"精确对齐的三件套"**
- 用今天学的：把 3 个立方体摆成一排，**间距精确 2 米、底面在同一高度、朝向一致**；
- 提示：`Shift+S → Cursor to Selected` 定基准 → `Selection to Cursor (Keep Offset)` 搬整排 → `Selection to Grid` 收尾。
- 这个练习直接对应以后"一排包装盒/一排瓶子"的基本功。

## 六、小提示与常见坑

- **坑 1：以为"移动游标"会移动物体。** 游标和物体是两码事。游标只是"参照点"，物体不动。
- **坑 2：`Shift+右键` 变成了"加选物体"。** `Shift+右键` 是放游标，`右键` 才是取消/上下文菜单；如果在物体上点，容易误触。建议在**空白处**点。
- **坑 3：Set Origin 之后物体"跳走了"。** 别慌，不是物体动了，是**橙点（原点）**动了。按 `Alt+G` 能把物体位置归零，但你通常不需要——只要记住"原点可以随便挪，模型本体不动"。
- **坑 4：磁铁开着忘了关。** 之后做精细拖拽会处处"被吸住"，怀疑人生。**练完立刻 `Shift+Tab` 关掉。**
- **坑 5：`Selection to Cursor` 忘了用 Keep Offset。** 多个物体一起搬时忘了勾 Keep Offset，它们会**全部叠到游标上**（挤成一坨）。要"整排搬"，一定用 `Selection to Cursor (Keep Offset)`。
- **坑 6：快捷键版本差异。** `Shift+Ctrl+Alt+C` 在部分版本/输入法下按不出来。**永远优先用菜单 `Object → Set Origin`**，稳。
- **心态提示**：本课没有新模型，全是"操作规范"。但它是**从"能摆东西"到"能对齐工程"的分水岭**——以后做包装盒、做硬表面道具，能不能对齐全靠今天这一课。
