## 一、今日学习知识点

### 1. 今天你学会"造复制军团"的机器

前两天你玩的是"**磨圆**"（细分曲面）和"**对称**"（镜像）。今天这位，是**修改器家族里的"复制机器"**：

> **一句话理解**：阵列修改器 = **给模型挂上一个"自动复制模块"，它按你给的间隔、方向、数量，把同一个物体复制成整整齐齐的一排 / 一圈 / 一大片。**

**打个比方**：以前做一排栏杆，你可能得 `Shift+D` 复制一根、`G` 移动一段、再复制、再移动……复制 20 次手都酸了。**阵列修改器 = 你只做一根栏杆，剩下 19 根它自己长出来**；而且你**改第一根，其余 19 根同时跟着变**。

**它和前两天那俩是什么关系？** 还是那套**修改器四大特性**（**非破坏性 / 可堆叠 / 可开关 / 要 Apply 才落地**，第 12 课讲过，今天完全通用）。区别只在分工：

| 修改器 | 干什么 |
| ------------- | ------------------------ |
| **Mirror 镜像** | 复制出**对称的另一半** |
| **Subdivision 细分** | 把方块**磨圆、变高模** |
| **Array 阵列** | 复制出**一整排 / 一整圈 / 一大片** |

---

### 2. 入口：先记住扳手这条老路

阵列修改器**没有**像细分那样的 `Ctrl+数字` 快捷方式，老老实实走菜单：

```
选中物体（物体模式）→ 右侧属性面板 →【蓝色扳手图标（Modifier）】
→ Add Modifier → Generate（生成）→ Array（阵列）
```

> **注意**：修改器是**物体级别**的，一定要在**物体模式**下加（第 05 课的纪律）。

加完之后，卡片里会出现**一堆参数**。别怕，今天只要吃透**四个**，剩下的都是配角。

---

### 3. 核心参数一：Count（数量）—— 变几份

面板里第一个要动的数值：

| 参数 | 通俗解释 |
| ------------------- | -------------------------------------- |
| **Count（数量）** | 这个物体**一共出现几个**（含原本那一个） |

- `Count = 1` → 只有原来那一个（**看起来像"没生效"**）；
- `Count = 5` → 沿某个方向并排出现 5 个；
- `Count = 10` → 10 个。

> **新手第一次最常见的懵**：加完 Array 后**画面毫无变化**——因为默认 **Count = 1 且偏移 = 0**，10 个复制体全**叠在同一个位置**。**去把 Count 改成 3、把偏移改一个方向**，立刻见效。

**进阶：Fit Type（适配方式）** —— 除了"我要几个"，还有"我要多长"：

| Fit Type | 意思 |
| ------------------ | ------------------------------------ |
| **Fixed Count** | 按**数量**（默认，我给你几个就是几个） |
| **Fit Length** | 按**总长度**（我框一段距离，你自动塞满） |
| **Fit Curve** | 按**一条曲线**的长度铺满（配合曲线用，选做） |

**今天先用 Fixed Count 就行**，另外两个知道名字即可。

---

### 4. 核心参数二 & 三：两种偏移，别搞混

这是本课的**核心难点**，也是新手翻车最多的地方。阵列面板里管间隔的参数**有两套**，它们长得像，作用完全不同：

| 参数 | 单位是什么 | 通俗解释 |
| ------------------------------ | ---------------------- | --------------------------------------------------- |
| **Relative Offset（相对偏移）** | **物体自身尺寸的倍数** | `X = 1` 表示"往右挪**一整个自己**那么宽"，正好首尾相接 |
| **Constant Offset（常量偏移）** | **绝对单位（米）** | `X = 2` 表示"往右挪 **2 米**"，跟物体多大没关系 |

> **一句话记住**：**Relative 按"自己有多宽"算，Constant 按"世界尺子"算。**

**怎么选？**

- 想让复制体**紧挨着、刚好不重叠** → 用 **Relative Offset**（把对应轴设成 `1`，正好一个贴一个）；
- 想让它们**间距固定成某个实际距离**（比如"每根柱子间隔 0.5 米"） → 用 **Constant Offset**；
- 两个可以**同时开**，效果叠加。

**还有个倍数系数 Factor**：Relative Offset 下面那个 `Factor` 默认 `1.0`，调大就是"**把间隔再乘以几倍**"——想拉开距离又懒得算米数时，直接调它最方便。

**方向怎么定？** Offset 有 **X / Y / Z 三行**，填在哪个轴就往哪个轴复制，三行可以同时填（斜着复制、阶梯式复制）。

> **重要**：偏移用的是**物体的局部方向**。所以老规矩——**尺寸动过就先 `Ctrl+A` 应用缩放**，否则"一整个自己"算出来是错的（铁律，第 05/11/13 课都出现过）。

---

### 5. 核心参数四：Object Offset（物体偏移）—— 环形阵列的钥匙

上面两套偏移都是"**直线复制**"。可我要做**一圈**（齿轮、花瓣、螺旋叶片、环形座位）怎么办？

**答案：Object Offset —— 找一个"参照物"来当复制的控制器。**

它的逻辑很妙：

```
把另一个物体（一般是一个 Empty 空物体）设为参照
→ 阵列就会按"你和这个参照物之间的位置差 + 角度差"来复制
→ 参照物转了 30°，每个复制体就比前一个多转 30°
```

**典型做法（环形阵列）**：

1. 在**世界原点**建一个 **Empty**（`Shift+A → Empty → Plain Axes`）；
2. 把你的小零件（比如一片花瓣）挪到**离原点一段距离**的位置；
3. 阵列面板里勾上 **Object**（或 **Object Offset**），把**参照物填成那个 Empty**；
4. 去**旋转那个 Empty**（按 `R`） → **看花瓣一圈一圈长出来**；
5. 想让一圈排满 12 个 → 每次转 `360 ÷ 12 = 30°`，把 `Count` 设成 12。

> **心法**：**Object Offset 里，真正在"控制复制"的是参照物的位置和旋转**——参照物转多少度，相邻两个复制体就相差多少度。

**回到直线场景**：也能用 Object Offset 做"**沿斜线阶梯复制**"（参照物斜着放），不过直线复制一般直接用 Relative / Constant 更快。

---

### 6. Merge：把首尾相接的地方焊起来

直线阵列常见一个现象：**复制体和前一个"贴"在一起，中间有条看不见的缝**。其实那是**两组重叠的顶点**在里面，看着没事，一细看可能有缝、进编辑模式点也特别多。

**解决办法：勾上 `Merge`（合并）和 `First and Last`。**

- 勾了它，**相邻两个复制体在接缝处会把重叠顶点自动合并**，变成真正连成一体；
- 合并阈值不够时，调大一点点旁边的 **Merge Threshold**（默认 `0.001` 米）。

> **一句话记住**：**要"连成一根"就勾 Merge；要"保持独立小块"就别勾。** 做栏杆、楼梯一般保持独立；做"一根弯折的管子/履带"就要勾。

---

### 7. 修改器栈顺序：又来了（复盘 12/13 课）

阵列经常和镜像、细分**一起出现**，顺序不一样，结果差很远。老规矩：**修改器从上往下依次执行**。

| 栈顺序 | 效果 | 什么时候用 |
| ------------------------------- | --------------------------------------- | ---------------------------------- |
| **Mirror 在上 → Array 在下** | 先补出对称的整体，再把整体复制一排 | 栏杆：一根柱子先做对称造型，再阵列成一排 |
| **Array 在上 → Mirror 在下** | 先复制一排，再整体镜像出对面一排 | 中间一条过道，两边各一排栏杆 |

**Array 和 Subdivision 的顺序**：一般 **Array 在上、Subdivision 在下**，让细分负责把这"一队复制体"统一磨圆；反过来的话，**每个复制体先被磨圆再被复制，面数会暴涨**。

> **结论照旧**：**拿不准就自己拖顺序试**——拖修改器卡片右上角的**十字手柄**上下移动，一眼看出区别。

## 二、学习目标

学完本课你应该能：

1. 说清**阵列修改器**做了什么，以及它和**镜像 / 细分**在"修改器特性"上的共同点；
2. 会从**扳手 → Add Modifier → Generate → Array** 加阵列，知道 **Count = 1 时"看不出变化"是正常的**；
3. 分清 **Relative Offset（按自身尺寸倍数）和 Constant Offset（按绝对单位）**，知道什么时候用哪个；
4. 会用 **Object Offset + Empty** 做出**环形阵列**（齿轮 / 花瓣 / 环形位置）；
5. 会用 **Merge** 把首尾相接的复制体焊成一根；
6. 知道 **Array 和 Mirror / Subdivision 的栈顺序**，并会自己拖顺序对比效果；
7. 能独立做出**一排栏杆或一段楼梯**，并**记得导出前 Apply、Apply 前先存盘**。

## 三、实操练习任务

### 练习 1 · 第一次让物体"分身"（5 分钟）

**先破掉"加完没变化"这个懵。**

1. `Shift+A` 加一个 **Cube**，按 `S` 缩放成一根**细长柱子**（比如 `S → Z → 2`，再 `S → X → 0.2`）；
2. 打开**扳手面板 → Add Modifier → Generate → Array**；
3. **看结果**：**画面没变**——因为 `Count = 1`、偏移都是 0，复制体全叠在一起；
4. 把 **Count 改成 3** → 还是没变（因为偏移是 0，三个叠在同一个位置）；
5. 打开 **Relative Offset**，把 **X 设成 1** → **见证奇迹**：柱子瞬间变成**并排三根、首尾相接**；
6. 把 Count 改成 **8**、Relative X 改为 `1.2` → 变成**八根带间隙的栏杆**。

> **目的**：建立最强条件反射——**阵列 = Count（几个）+ Offset（往哪挪多少）**，两个都要给值才生效。

---

### 练习 2 · Relative vs Constant，亲手感受差别（8 分钟）

**这是本课最需要"手感"的一栏。**

1. 接练习 1 的柱子，先把 Count 调回 **4**，Relative X 调回 `1`；
2. **记住现在的间距**（首尾相接）；
3. 取消勾选 **Relative Offset**，改勾 **Constant Offset**，X 填 **0.5** → **看变化**：间距不再跟柱子大小挂钩，变成**固定 0.5 米的间距**；
4. **验证**：回到物体模式，按 `S` 把柱子**整体放大一倍** → 切回来再看；
   - 用 **Relative** 时，间距**跟着变大**（"一个自己"变宽了）；
   - 用 **Constant** 时，间距**纹丝不动**（就是 0.5 米）；
5. 把 **Factor** 从 1.0 调到 2.0 → 观察**只用 Relative** 时间距翻倍。

> **目的**：把"**Relative 跟自己是多大有关，Constant 跟世界尺子有关**"变成亲身体感。

---

### 练习 3 · 三个方向一起填：做一段楼梯（12 分钟 · 主菜）

**直线阵列最经典的用法：台阶。**

1. 新建一个 Cube，压成**一级台阶**的形状（扁、长）：`S → Z → 0.2`（薄），`S → Y → 1`；
2. `Ctrl+A → Scale` **应用缩放**（铁律！后面要靠"一个自己"来算偏移）；
3. 加 **Array** 修改器：
   - **Count = 12**；
   - **Relative Offset**：`Y = 1`（沿 Y 方向，一级贴一级）；
   - 同时 **Constant Offset**：`Z = 0.25`（每一级**同时往上抬 0.25 米**）；
4. **看结果**：12 级台阶**边前进边上升**，一段楼梯就出来了；
5. **调参玩玩**：把 Constant Z 改成负数 → 变成**往下的台阶**；把 Count 改成 20 → 变成**超长楼梯**；
6. **Merge 实验**：勾上 `Merge` + `First and Last`，把 Constant Z 改成 **0** → 台阶被焊成**一条连续的坡道**（看清楚 Merge 干了什么）。

> **目的**：掌握**多轴同时偏移**（做楼梯、斜向排列、栏杆立柱），并理解 Merge 的实际作用。

---

### 练习 4 · Object Offset 做环形阵列（15 分钟 · 难点）

**这就是"复制成一圈"的钥匙。**

1. `Shift+A → Empty → Plain Axes`，**保持它在世界原点**（位置 `0,0,0`）；按 `S` 把它放大到能看见（空物体本身不渲染，只是给你当把手）；
2. 新建一个**小方块**（以后当"花瓣 / 齿"），把它挪到**离原点一段距离**的地方，比如 `G → Y → 2`（也就是在原点旁边 2 米处）；顺手压扁拉长，做得像一片花瓣；
3. 选中**花瓣** → 加 **Array** 修改器：
   - **Count = 12**；
   - 勾上 **Object Offset**（有的版本就写 **Object**），把参照物**选成那个 Empty**；
4. **现在做什么？** —— **选中 Empty，按 `R` 旋转**（`R → Z`）：
   - 每转一点点，花瓣就**自动绕着原点排出一圈**；
   - 想让 12 片均匀铺满一圈 → 把 Empty 的 **Z 旋转设成 `360 ÷ 12 = 30°`**；
5. **看结果**：一朵"花瓣花"（或一个齿轮）出现；
6. **调参**：把 Empty 的 Z 旋转改成 `15°`，Count 仍为 12 → **12 片分摊在 180° 里**，挤成一串——**这就是角度和数量的关系**；
7. **加个颜色/材质区分（选做）**：给花瓣一个亮色，方便看清每一片。

> **目的**：**亲手把"Object Offset = 用参照物的旋转控制复制"整明白**。齿轮、螺旋叶片、餐桌环形座位、摩天轮，全靠这一招。

---

### 练习 5 · 综合小作品：一段带底座的栏杆（10 分钟）

把今天的东西串起来：

1. 做**一根栏杆立柱**（Cube 压细长 + `Ctrl+B` 小倒角，第 11 课学的手艺）；
2. 加 **Array**：Count = 10，Relative X = `1.5` → 排成一排立柱（**栏杆主体**）；
3. 做**一根横杆**（Cube 压成细长条）→ 加 **Array**：Count = 2，Constant Z 设高度 → **上下两根横杆**；
4. 做**一个底座**（Cube 压扁）→ 加 **Array**：Count = 10，Relative X = `1.5`（和立柱对齐）→ 一排底座；
5. **栈顺序练习**：给立柱同时加 **Mirror + Array**，先把 Array 拖到上面、再把 Mirror 拖到上面，**对比两种效果**，想想哪个更像你要的；
6. `Z` 切渲染预览看一眼 → **`Ctrl+S` 存成 `第14课_阵列修改器.blend`**。

> **目的**：走完一遍"**做一个 → 阵列成一片**"的真实流程；顺带把修改器栈顺序的手感练出来。

## 六、常见坑（速查表）

| 坑 | 现象 | 正确做法 |
| ---------------------------------- | ------------------------------ | -------------------------------------------- |
| **加完阵列画面没变化** | 以为没生效 | `Count = 1` 且偏移为 0，复制体**全叠在一起**了。把 Count 改大 + 填一个轴的偏移 |
| **改了 Count 还是不散开** | 只有一个 | **偏移忘了填**。至少要给 Relative 或 Constant 一个轴赋值 |
| **首尾相接却有小缝 / 点特别多** | 接缝不平整 | 勾 **Merge + First and Last**；必要时调大 **Merge Threshold** |
| **想首尾相接却总差一点** | 有重叠或有空隙 | 用 **Relative Offset = 1**（正好一个自己），别用 Constant 硬猜数值 |
| **间距不跟着物体缩放变** | 调大物体后间距不对 | 你用的是 **Constant**（固定米数）。要跟着变就切 **Relative** |
| **环形阵列排不出一圈** | 复制体挤成一堆或散不开 | 忘了设 **Object Offset** 的参照物，或**参照物不在世界原点**、没有旋转 |
| **环形阵列角度不对** | 12 个没铺满一圈 | 相邻角度 = `360 ÷ 数量`，把参照物的旋转设成这个值 |
| **删掉参照空物体后阵列崩了** | 复制体复位 / 报错 | **别删参照物**（它不渲染，留着即可）；或删前先把阵列 Apply |
| **面数暴涨、视口很卡** | 操作卡顿 | 提高 Count 前先**降低下游 Subdivision 的 Viewport Levels**；或把 Array 放到 Subdivision 下面 |
| **导出后只剩一个 / 还是单个** | FBX / glTF 里不对 | 导出前把修改器 **Apply**（第 12 课知识，**Apply 前先存盘**） |
| **偏移方向不对** | 复制体往奇怪方向跑 | 检查填的是**哪个轴**；方向基于**物体局部朝向**，物体转过的话先想清楚 |
| **尺寸动过再阵列，间距错乱** | "一个自己"算出来不对 | 先 **`Ctrl+A` → Scale** 应用缩放（铁律，第 05 / 11 / 13 课反复出现） |
| **在编辑模式里找阵列面板** | 找不到 | 修改器是**物体级别**，回**物体模式**加 / 改 |

## 七、下一课预告

**第 15 课：硬表面道具建模 —— 杯子**

到昨天为止，你手里已经攒齐了一整套"零件工具"：**挤出**（长身体）、**环切**（加关节）、**倒角**（磨边）、**镜像**（对称）、**细分**（磨圆）、**阵列**（复制）。今天你用阵列，把一个零件变成了**一整排、一整圈**——已经能搭出栏杆、楼梯、齿轮这种"重复结构"了。

**从下一课开始，我们不再单练"某个工具"，而是真刀真枪做成品道具**——第一个目标是**一个杯子**。别小看它：杯身要圆、杯口要有厚度、把手要接得住、底部还得有个小圈足。**它会把你这十几天学的每一样都用上一遍**。这就是"**会工具**"到"**会做东西**"的分水岭——**下一课见。**
