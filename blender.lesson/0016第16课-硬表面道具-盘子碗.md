## 一、今日学习知识点

昨天的杯子是"挤出流"：从圆柱出发，一层层 `E` 挤、`I` 抠。今天的盘子和碗打法完全不同——**画出剖面轮廓，绕轴转一圈，直接成型**。这是建模里"选对起手方式"的经典一课。

1. **核心新工具：Spin 车削（旋转成型）首次登场**
   - 作用：把一条线（剖面轮廓）绕着一根轴**旋转复制**，转满 360° 就是一个完整的旋转体。
   - 现实类比：陶艺拉坯、木工车床——转一圈，碗就出来了。Blender 的 Spin 就是数字车床。
   - 入口：**编辑模式** → 选中剖面线的全部顶点 → 左侧工具栏选 **Spin 工具**（或在菜单 Mesh → Spin；4.x 也可用快捷键 `Alt+E` 菜单里没有它，别混淆，Spin 在工具栏）。
   - 行业地位：碗、盘、瓶、花瓶、酒杯、罗马柱……一切"绕轴对称"的东西，Spin 都是第一选择，比逐圈挤出快十倍且弧线完美。

2. **第一步不是转，是画：剖面线怎么来**
   - Spin 的原材料是**一条顶点连成的折线**（就是物体的竖切剖面的一半）。
   - 画法：物体模式 `Shift+A` → Mesh → 任意小物体（常用 Plane 甚至单顶点）→ 进编辑模式删掉多余顶点 → 从**一个顶点**开始，`E` 逐点挤出，像"描点连线"一样画出盘子的侧剖面轮廓。
   - 剖面线画在哪：在**前视图**（`小键盘1`）里画，线沿 Z 轴方向延伸，这是标准姿势。
   - 顶点的顺序就是连线顺序，顺序乱了转出来就是麻花。

3. **Spin 的三个关键参数（左下角操作面板）**
   - **Steps（段数）**：转一圈分成多少份，类似圆柱的段数。特写物体给 32 起步，太低会棱角分明。
   - **Angle（角度）**：默认 360° 转满一圈；改成 180° 就得到半个碗。
   - **轴心（最关键，也是最大的坑）**：Spin 绕的不是物体原点，而是**3D 游标的位置** + 当前视图朝向决定的轴。轴心放错了，转出来的不是碗，是"歪月亮"。
   - 直接串起第 04 课：画完剖面线后，用 `Shift+S` → **Cursor to World Origin** 把游标钉回世界原点，让碗绕世界中心转——这是本课的黄金前置动作。

4. **车削之后的两件收尾工作**
   - **去重顶点**：转满 360° 时，起点和终点的顶点会重叠在一起（不合并的话那里有一条缝）。选中全部顶点 → `M` → **By Distance**（按距离合并），左下角提示"Merged xx vertices"就对了。
   - **法线检查**：车削很容易转出"内翻"的面（内壁朝外）。叠加层里打开 **Face Orientation**（面朝向）：蓝=正面朝外、红=翻面。红了就全选 → `Shift+N` 重算法线。

5. **Spin vs Screw 修改器（一句话带过，知道即可）**
   - 修改器里有个 Screw（螺旋），也能做旋转体，还能做弹簧螺旋线。区别：Spin 是**一次性**把网格转出来（直接生成实体网格），Screw 是**非破坏性**的修改器（参数随时可改）。初学阶段用 Spin，直接、所见即所得。

## 二、学习目标

完成本课后，你应该能够：

1. 理解"剖面线 + 车削"的建模思路，知道什么时候用 Spin 而不是挤出。
2. 用 `E` 逐点挤出画出一条光滑合理的盘子/碗剖面轮廓。
3. 正确摆放 3D 游标当轴心，用 Spin 一次转出完整旋转体。
4. 完成车削后标准收尾：`M` 按距离合并 + Face Orientation 法线检查。
5. 交付盘子和碗各一个成品，阶段 2 宣告通关。

## 三、实操练习任务

**准备**：新建文件，删掉默认立方体。今天的核心手感是"像用铅笔画画一样画剖面线"，别急。

### 练习 1：认识轴心——先故意转个歪的（10 分钟，必做的踩坑练习）

1. `Shift+A` → Mesh → **Plane**（平面）。`Tab` 进编辑模式，`M` → Merge → **At Center**，四个顶点合成一个顶点。
2. `小键盘1` 切到前视图。选中这个顶点，`E` 向上挤出一段（这就有了一条两点的小线）。
3. 切回物体模式，把游标**随便挪到别处**（`Shift+右键` 点一下空白处即可移动游标）。
4. 回到编辑模式，选中两个顶点，工具栏点 **Spin**，左下角面板 Steps 设 32、Angle 保持 360。
5. 看结果：转出来的东西绕着"游标"转，轴心不对就是一盘散沙。**记住这个画面**——这就是本课最大坑的实体化。
6. `Ctrl+Z` 撤销。物体模式下 `Shift+S` → **Cursor to World Origin** 把游标钉回原点，再 Spin 一次——这次它绕着世界中心转出了一个规规矩矩的圆环。

### 练习 2：画盘子的剖面线（15 分钟，本课主菜之一）

7. 重新来一个单顶点（`Shift+A` → Mesh → Plane → 编辑模式合并到中心）。
8. 物体模式把顶点挪到**世界原点右侧一点**（它将成为盘子的中心起点），`Tab` 进编辑模式，`小键盘1` 前视图。
9. `E` 逐点挤出，画出盘子剖面（从左到右，即"从盘心到盘沿"）：
   - 盘心：水平向右挤 2~3 个点（盘底平面）。
   - 盘壁：向上斜着挤 2~3 个点（盘子微微抬起的弧度）。
   - 盘沿翻边：向外再挤 1~2 个点，微微下勾（盘沿那道优雅的翻边弧线就靠这两个点带出）。
   - **厚度**：盘子不是纸片——从盘沿**原路折返**，把内壁的剖面也画回来，一直画到盘底下方，最后停在盘心正下方。整条线是"一个扁扁的 U 形夹层"。
10. 剖面线的"水平点尽量水平、竖直点尽量竖直"：挤出时按住 `Ctrl` 可以吸附角度，或直接输数值（`E` → `X`/`Z` → 数字）。

### 练习 3：Spin 车削盘子（10 分钟）

11. `Shift+S` → Cursor to World Origin（黄金前置动作，每次 Spin 前默念）。
12. `A` 全选剖面线所有顶点，工具栏 **Spin**，Steps = **32**，Angle = 360。
13. 成了——一个盘子转出来了。但没结束：
    - `A` 全选 → `M` → **By Distance**，合并重叠顶点（留意左下角提示合并了几个）。
    - 右上角叠加层 → **Face Orientation**：盘子外侧应该是蓝色。如果有红色，全选后 `Shift+N` 修复。
14. 物体模式 `Ctrl+2` 加细分曲面。盘子塌了？盘底和盘沿加环切（`Ctrl+R`）贴近边缘保挺——这是第 13/15 课的老朋友了。

### 练习 4：碗——剖面线决定一切（15 分钟）

15. 同样的流程再来一遍，这次画碗的剖面：
    - 碗心底部：一小段水平线（碗底，略厚）。
    - 碗壁：一条向外鼓的弧线（用 4~5 个点描出圆润的鼓肚）。
    - 碗口：弧线收尾，微微外翻一点（防止"罐头感"）。
    - 折返画出内壁和壁厚，闭合到碗心下方。
16. 游标回原点 → 全选 → Spin（32 段 / 360°）→ `M` By Distance → 法线检查 → `Ctrl+2` 细分。
17. 碗底太"飘"的话：选碗底外圈循环边，`E`+`S` 收出一圈矮圈足，再 `Ctrl+B` 小倒角——直接复用第 15 课杯子的圈足手法。

### 练习 5：一菜一汤组合交付（5 分钟）

18. 把盘子和碗摆在一起（`G` 移动），碗放进盘子上方，构图摆好看点。
19. 各给一个预览色：材质面板 → New → Base Color（瓷白碗 + 深灰盘就很耐看）。
20. `Ctrl+Shift+S` 另存为：`盘碗组合-v1.blend`，放进你的项目文件夹。

## 五、课后小作业

1. **必做**：不看步骤，凭记忆重做一遍碗。卡住时记录"卡在哪一步"——大概率是游标没回原点或忘了合并顶点，那就是你要刻进肌肉记忆的地方。
2. **必做**：画三个不同形状的剖面线（深盘 / 浅碟 / 高脚杯的杯肚），各 Spin 一次。体会"剖面线就是灵魂"——车削只是执行器，形状全在你画的那条线上。
3. **选做**：挑战一个**花瓶**或**红酒杯**：剖面线更长、弧线更多，但流程一模一样。能做出来，旋转体你就毕业了。
4. **思考题**（不用做）：Spin 转出来的物体，侧面是一圈一圈的四边面还是三角面？放大碗口看看。（提示：这条观察直通下一课——四边面与拓扑。）

## 六、常见坑（本课高发）

1. **Spin 转出来是一坨麻花/歪月亮**：99% 是轴心问题。Spin 绕的是 **3D 游标**，不是物体原点。先 `Shift+S` → Cursor to World Origin，再转。
2. **转出来的东西方向不对**（比如碗"躺"着转）：Spin 的旋转轴由**当前视图朝向**决定。画剖面线和执行 Spin 都要在正交视图里（`小键盘1` 前视图），别在透视图随手一转。
3. **转满 360° 后碗口/碗底有一条隐约的缝**：起点终点顶点没合并。全选 → `M` → By Distance。
4. **碗内侧看不到面/颜色发暗**：法线内翻了。打开 Face Orientation 看红蓝，红了就全选 `Shift+N`。
5. **剖面线顶点顺序画反/交叉**，转出来中间打结：顶点挤出顺序就是连线顺序，`Ctrl+Z` 回到顺序正确的状态，逐点检查。
6. **Steps 开太低（如 8~12 段）**：碗壁棱角明显，像多边形盘子。特写物体 32 段起步，参数在 Spin 的瞬间左下角面板改，事后要重做。
7. **加了细分后盘沿的翻边被磨没**：翻边附近环切（`Ctrl+R`）贴近保挺，或 `Shift+E` Crease——第 13/15 课的肌肉记忆该派上用场了。
8. **剖面线里水平段画歪了**，转出来盘底凹凸不平：挤出时锁轴（`E` → `Z` 或 `X`）再输数值，别徒手拖。
