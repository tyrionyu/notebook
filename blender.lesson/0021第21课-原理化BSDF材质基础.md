# 第 21 课 · 原理化 BSDF 材质基础

> 阶段 4 · 材质灯光渲染 开篇
> 今天开始，你的模型要从「灰模」变成「有颜色的东西」。前面 20 课我们都在做形状，这一课解锁 Blender 的**材质系统**。

---

## 一、今日学习知识点

1. **什么是材质（Material）**：材质 = 物体表面的「外观配方」，决定它是金属、塑料、玻璃还是木头。同一个物体可以换不同材质，模型形状完全不变。
2. **原理化 BSDF（Principled BSDF）**：Blender 默认的「万能着色器」。以前做金属、玻璃、塑料要堆十几个节点，现在**一个节点管所有**——颜色、金属度、粗糙度、透明度全在里面。
3. **着色器编辑器（Shader Editor）**：材质是用「节点」拼出来的，节点之间有连线。今天先认识这个面板，看懂一个节点和它的端口。
4. **材质槽（Material Slots）**：一个物体可以挂多个材质，分配给不同的面。今天的重点是先挂上第一个材质。
5. **给灰模上第一个颜色**：把 Base Color（基础色）从默认的灰白改成你要的颜色，这就是材质入门的全部核心。

学完今天，你要能做到：

## 三、实操练习任务（10 步）

> 建议用第 16 课的盘/碗，或随便新建一个默认 Cube。跟着做一遍。

1. **打开着色器编辑器**：把某个视图区切换成 Shader Editor（着色器编辑器）。找不到就点视图左上角的编辑器类型下拉菜单，选那个像圆点连线的图标。
2. **选中物体**：物体模式下选中你的模型，然后点编辑器底部那个「+ New / 新建」按钮（在 Material 属性那块，或编辑器底部）。
3. **看节点**：出现两个默认节点——左边一个 **Principled BSDF**，右边一个 **Material Output（材质输出）**，中间一根线连着。
4. **点开 Base Color**：点 Principled BSDF 节点上「Base Color」旁边那个色块，弹出颜色选择器。
5. **换个颜色**：把颜色改成蓝色（或其他任意颜色），观察 3D 视口里模型立刻变色。
6. **改粗糙度 Roughness**：把 Roughness 从 1 往 0 拖，看模型表面从哑光（1）变成反光油亮（0）。
7. **改金属度 Metallic**：把 Metallic 从 0 拖到 1，看模型变成金属质感。（今天只感受，参数原理明天第 22 课详解）
8. **断开连线看看**：点住 BSDF 和 Material Output 之间的线，拖走/删掉，看视口变黑——体会「线」就是数据流动的通道，再连回去。
9. **看材质槽**：在右侧属性栏的材质图标（一个球）下，看到你刚建的材质名字。点「+」可以再加第二个材质槽。
10. **换个物体试试**：选中另一个物体，点「新建」再建一个不同颜色的材质，体会「每个物体各自有配方」。

## 六、常见坑（新手必看）

1. **找不到变色按钮**：颜色不在「物体」属性里，在「材质」属性（球图标）或着色器编辑器里。先确认你点的是球图标，不是方块图标。
2. **改了颜色模型没反应**：先确认①选中了物体 ②物体有材质（没点过「新建」就没有）③视口右上角显示模式是「材质预览 / Solid+材质」而非纯线框。切到 Material Preview（材质预览，视口右上角四个球，选第三个）才能看到颜色。
3. **把节点删没了**：删错节点导致视口变黑/变紫。不用慌，重新点「新建」即可；或 Shift+A 在编辑器里重新添加节点。
4. **Roughness 拉到 0 看不到反光**：反光依赖环境/光照，材质预览模式下默认有环境光能看到。实在不明显就等第 23 课三点布光后再回来看。
5. **误把「材质」和「纹理/贴图」搞混**：今天只学「材质」（颜色、质感），「贴图」（往表面贴图片）是阶段 5 第 28 课的事，先不用碰。
