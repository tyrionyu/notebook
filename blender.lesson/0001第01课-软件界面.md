## 一、今日学习知识点

### 1. Blender 界面的 5 个主要区域

打开 Blender 后，先别急着建模。用鼠标把下面 5 个区域各点一遍，眼睛跟着手走：

| 区域                    | 位置         | 作用                          |
| --------------------- | ---------- | --------------------------- |
| **顶部菜单栏 / 顶栏**        | 屏幕最上方一条    | 文件、编辑、渲染等全局菜单；右侧是**工作区标签**  |
| **3D 视口（Viewport）**   | 中间最大的一块    | 你将来 90% 时间待的地方，看模型、改模型都在这   |
| **工具栏（Toolbar）**      | 视口**左侧**竖条 | 选择、移动、旋转、缩放等工具按钮（按 `T` 开/关） |
| **大纲视图（Outliner）**    | 右上角        | 列出场景里所有物体、灯光、相机的"名单"，也叫层级树  |
| **属性编辑器（Properties）** | 右下角        | 一列竖排图标：渲染、输出、世界、物体、修改器、材质…… |

> 记忆口诀：**上菜单、中视口、右名单、右下属性、左工具**。

### 2. "编辑器"思维 —— Blender 界面最核心的设计

Blender 的每一个区域（包括 3D 视口）本质上都是一个可替换的**编辑器（Editor）**。  
每个区域的**左上角**都有一个图标：

- 点击这个图标 → 弹出编辑器类型菜单（3D 视图、大纲视图、属性、图像编辑器、文本编辑器、时间线……）；
- 也就是说：右上角那块地方，你随时可以把它从"大纲视图"换成别的，再换回来。**界面是活的，不会坏。**

### 3. 工作区（Workspace）—— 官方预置的界面布局

顶栏中部有一排标签：`Layout（布局）`、`Modeling（建模）`、`Sculpting（雕刻）`、`UV Editing`、`Texture Paint`、`Shading`、`Animation`、`Rendering`、`Compositing`、`Geometry Nodes`。

点一下，整个界面布局就为那个任务重组了 —— 这是官方把常用布局打包好给你的。**零基础阶段你只用得上 `Layout` 和 `Modeling` 两个。**

### 4. 3D 视口内部的关键开关

| 控件                        | 位置                | 作用                            |
| ------------------------- | ----------------- | ----------------------------- |
| **模式切换**                  | 视口左上角（默认显示"物体模式"） | 切换物体模式 / 编辑模式 / 雕刻模式等         |
| **视图叠加（Overlays）**        | 视口右上角第一个按钮        | 是否显示网格线、坐标轴、物体轮廓              |
| **着色模式**                  | 视口右上角四个小球图标       | 线框 / 实体 / 材质预览 / 渲染预览         |
| **导航轴（Navigation Gizmo）** | 视口右上角轴球           | 点击它可快速对齐到前/顶/右视图              |
| **状态栏**                   | 屏幕最底部一条           | 提示当前鼠标悬停处能做什么操作 —— **卡住就看这里** |

### 5. 属性编辑器（Properties）的图标顺序

右下角那一列竖排图标，从上往下常见的几个：

- 🔧 扳手 = **修改器（Modifiers）**（后面阶段 2 的主战场）
- 🎨 圆点球 = **材质属性**
- 📷 = **渲染属性**（阶段 4 用）
- 🌍 地球 = **世界环境**

> 找不到某个功能时，先想"它属于物体本身还是属于场景"，再在这一列图标里从上往下扫。

## 三、实操练习任务

> 全程不要求做出作品，只做"熟悉动作"，做错也没关系，`Ctrl+Z` 撤销、重启软件都能恢复。

1. **认区域**：打开 Blender，用鼠标依次指向界面 5 个区域，心里默念名称。
2. **换编辑器**：把右上角的"大纲视图"区域，左上角图标点开 → 换成"文本编辑器"（Text Editor）→ 再换回"大纲视图"。感受"界面是活的"。
3. **切工作区**：顶栏点 `Modeling`，看看界面怎么变的；再点回 `Layout`。
4. **切着色模式**：视口右上角四个小球，挨个点，观察默认立方体的外观变化（线框 → 实体 → 材质预览 → 渲染预览）。**先建一个印象就够了，不用懂原理。**
5. **开关侧栏**：按 `T` 关掉左侧工具栏，再按 `T` 打开；按 `N` 打开右侧侧边栏，再按 `N` 关掉。
6. **调区域大小**：鼠标移到两个区域之间的边界线，出现双向箭头后左右拖动。
7. **最大化区域**（超实用）：鼠标悬停在 3D 视口上 → 按 `Ctrl + 空格` 最大化 → 再按一次还原。
8. **切中文界面**：`Edit（编辑）→ Preferences（偏好设置）→ Interface（界面）→ Translation（翻译）→ Language → 简体中文`。
   > 注意：Blender 的中文翻译不完整，部分术语仍是英文。**建议菜单用中文、但把"New Data"（新数据）的勾选项保持不勾**，否则新建物体名称会变成中文，后期搜教程会对不上。若你决定用英文界面，也完全可以 —— 后面课程里我会中英并列写快捷键。

## 六、小提示与常见坑

- **不要嫌"界面课"没意思就跳过。** 后面 34 课里，90% 的卡顿都来自"我不知道某个面板在哪"。这一课是给后面省时间的。
- **不要一开始就改主题、改布局、装一堆插件。** 先用官方默认布局，等 Stage 4 之后你自然知道想改什么。
- **视口右上角那四个小球** 现在看不懂正常，Phase 4 会专门讲。
- **手酸是正常的。** 零基础第一天手指不熟悉快捷键很常见，第 2 课开始会逐渐顺手。
