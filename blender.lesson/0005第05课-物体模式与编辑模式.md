## 一、今日学习知识点

### 1. 一句话讲清两种模式的区别

Blender 里所有的物体（Mesh 网格物体）都有两副"面孔"，用 `Tab` 键来回切：

| | **物体模式 Object Mode** | **编辑模式 Edit Mode** |
| --- | --- | --- |
| 操作对象 | **整个物体**（把自己当一个积木块） | **物体内部的点/线/面**（把积木当成一堆零件） |
| 能做什么 | 移动、旋转、缩放、加修改器、改材质、复制、对齐 | 改形状、改布线、挤出、环切、倒角、焊接顶点 |
| 典型工具 | `G/R/S`、`Shift+S`、`Ctrl+A`、修改器面板 | `E` 挤出、`Ctrl+R` 环切、`Ctrl+B` 倒角、`M` 合并 |
| 比喻 | 你手里拿着**一个积木**在房间里摆 | 你蹲下来**雕刻这一块积木本身** |

> 一句话记住：**物体模式管"摆放"，编辑模式管"塑形"。**
> 想搬动 → 物体模式；想改形状 → 编辑模式。

### 2. 为什么必须分成两种模式

新手会问："为什么不能直接捏点？非要切模式？"

因为这两种操作**在数学上冲突**：

- "移动整个物体" = 改它的**位置坐标**（Location）；
- "移动一个顶点" = 改**顶点数据**（Mesh data）。

如果混在一起，你拖动画面时，Blender 无法判断你是想搬整个盒子，还是想拽盒子的一个角。所以它用 `Tab` 把"整体操作"和"局部编辑"强行分开。**这不是麻烦，这是保护你不出错。**

### 3. `Tab` 键：切换键（本课唯一必须背熟的键）

```
选中物体 → 按 Tab → 进入编辑模式
再按 Tab → 退回物体模式
```

**进入编辑模式的两个前提（必须同时满足）：**

1. **有物体被选中**（橙色描边那个）；
2. **它是最后一层被点选的 "Active（活动）物体"**——多个物体被选中时，只有**亮橙色**的那个能进编辑模式。

**新手第一坑：**没选中物体就按 `Tab`，什么都没发生（或在空场景里报错）。先 `左键点击` 选中它。

**多物体同编（小技巧）：**选中 A、B 两个物体后按 `Tab`，会**同时进入两者的编辑模式**，可以一起改。想只改一个，就只选中它。

### 4. 编辑模式里的三个"子层级"：顶点 / 边 / 面

进入编辑模式后，键盘上方数字键 **`1` / `2` / `3`** 切换选择层级：

| 按键 | 层级 | 名字 | 图标 |
| --- | --- | --- | --- |
| **`1`** | 点 | **Vertex（顶点）** | 三个小点连成三角 |
| **`2`** | 线 | **Edge（边）** | 一条线段 |
| **`3`** | 面 | **Face（面）** | 一个填充方块 |

> 也可以点左上角那三个小图标切换。**本课先都在物体模式里练，第 6 课专门练这三个层级的选择。** 今天只要知道"按下 `1/2/3` 能切"就够了。

### 5. `Ctrl+A`：应用变换（Apply Transform）——本课最重要的"隐藏知识点"

这是个**必须在物体模式做的事**，也是新手最容易踩的坑。

**问题背景：**你在物体模式把一个立方体 `S` 拉成 2 倍大，再 `R` 转了 30°。此时：

- 物体的 **Scale 显示是 (2,2,2)**、**Rotation 是 30°**；
- 但它的**真实顶点数据还是"原始大小、没旋转"的立方体**。

结果就是：一进编辑模式去点顶点、一加修改器（尤其 Bevel 倒角、Array 阵列），尺寸全乱、倒角粗细不均——因为修改器读的是"原始数据"，而你看到的是"被缩放后的假象"。

**解决方法：**物体模式选中物体 → `Ctrl + A` → 选 **All Transforms（全部变换）**。

**效果：**把 Scale 归位成 (1,1,1)、Rotation 归位成 0，同时**把这些变换"烙"进顶点数据里**。外形不变，但数据变干净了。

> **铁律（今天就刻进脑子）：**
> **`G/R/S` 变过形之后，只要接下来要进编辑模式或加修改器，先 `Ctrl+A → All Transforms`。**
> 这是从"随便玩玩"走向"能做出干净模型"的分水岭。

`Ctrl+A` 菜单四个选项：

| 选项 | 作用 | 什么时候用 |
| --- | --- | --- |
| **All Transforms** | 位置+旋转+缩放一起应用 | **默认就用它**（最常用） |
| **Rotation & Scale** | 只应用旋转和缩放，保留位置 | 想保留物体的世界位置不动 |
| **Scale** | 只应用缩放（归成 1） | 只被缩放时 |
| **Rotation** | 只应用旋转（归成 0） | 只被旋转时 |

### 6. 两种模式各自的"快捷键地图"（别混用）

**物体模式：**
```
G / R / S          移动 / 旋转 / 缩放
Shift+S            吸附菜单
Ctrl+A             应用变换
Shift+D            复制（Duplicate）
Alt+D              关联复制
Shift+A            新建物体
N                  右侧属性面板
```

**编辑模式：**
```
Tab                退回物体模式
1 / 2 / 3          点 / 边 / 面 层级
A / Alt+A          全选 / 全不选
Ctrl+R             环切 Loop Cut（第 10 课）
E                  挤出 Extrude（第 9 课）
Ctrl+B             倒角 Bevel（第 11 课）
M                  合并顶点 Merge
F                  用选中顶点/边造一个面
X                  删除（选中点/线/面）
G / G G            移动（连按两次 = 沿边滑动）
```

> 注意：`E`、`Ctrl+R`、`Ctrl+B` 这些键**只在编辑模式生效**。在物体模式按 `E` 没反应——不是你按错了，是模式不对。**新手 80% 的"快捷键不管用"都是模式没切对。**

### 7. 退出编辑模式的三个入口（都行）

1. `Tab`（最快）；
2. 左上角**模式下拉菜单**（写着 Object Mode / Edit Mode 的那个）→ 点开改；
3. 该模式左上角菜单 `Mesh → ...` 里也能退出。

> **重要提醒：进入编辑模式时"修改器面板会变灰"**——这是正常的。改完形状按 `Tab` 回物体模式，修改器立刻恢复生效。

## 三、实操练习任务

> 全程用默认立方体，重点是**亲手体验"模式不对 = 快捷键失效"和"不 Apply 就翻车"两件事**。

**1. 感受两种模式**
- 打开默认立方体，按 `Tab` → 左上角模式变成 **Edit Mode**，立方体所有边变成**白色**（进入可编辑状态）；
- 再按 `Tab` → 回 **Object Mode**，白色消失；
- 反复按 3 次 `Tab`，建立"这就是切换键"的肌肉记忆。

**2. 亲手体验"模式不对，快捷键失灵"**
- 在**物体模式**按 `E`（挤出）→ 什么都没发生；
- 按 `Tab` 进**编辑模式**，按 `A` 全选，再按 `E` → 立方体被"挤出"了一个新高度；
- `Ctrl+Z` 撤销（别把立方体弄坏了）；
- 结论记下来：**快捷键没反应，先看左上角的模式。**

**3. 三层级切换**
- 进编辑模式，按 `1` → 看到 8 个**小点**（顶点）；
- 按 `2` → 变成 **12 条边**；
- 按 `3` → 变成 **6 个面**；
- 用鼠标点一个面，它变橙色 = 被选中了。点 `3` 再按 `A` 可以全选所有面。

**4. 复现"翻车"（今天最关键的一步）**
- 回物体模式 `Tab`；
- 按 `S` 把立方体放大到 2 倍（看 `N` 面板 Scale = 2）；
- 按 `S` 再压扁一点（Scale Z = 0.5）；
- **直接**（先别 Apply）进编辑模式 `Tab`，`Ctrl+B` 拉一个倒角；
- 观察：**倒角粗细明显不均匀**，某些角歪了 —— 这就是"未应用变换"的典型症状。
- `Ctrl+Z` 撤销，回物体模式。

**5. 用 `Ctrl+A` 修好它**
- 物体模式，`N` 面板里看到 Scale 是 (2,2,0.5)；
- 按 `Ctrl + A` → 选 **All Transforms**；
- 立刻看 `N` 面板：**Scale 变回 (1,1,1)**，Rotation 归 0，但**立方体外形一点没变**；
- 再进编辑模式，`Ctrl+B` 倒角 → **这次粗细均匀了**。
- 记住这个对比：**Apply 前 vs Apply 后，同样的倒角操作，结果完全不同。**

**6. 多物体同编**
- 回物体模式，`Shift+A → Mesh → UV Sphere` 加个球；
- 选中立方体和球（`Shift` 分别点，最后一要点**立方体**让它成为"亮橙色的 Active"）；
- 按 `Tab` → 两个物体**同时**进入编辑模式；
- 观察：球和立方体的点都显示出来了，一起编辑；
- `Tab` 退出。

**7. 在编辑模式里"搬零件"（体会区别）**
- 只选中立方体 → `Tab` 进编辑模式 → 按 `3` 面层级 → 点选**顶面**；
- 按 `G` → 拖动 → **只有顶面动了，立方体被拉高**；
- 再 `Tab` 回物体模式，按 `G` → 拖动 → **整个物体一起动**；
- 对比感受：同样按 `G`，模式不同，结果完全不同。

**8. 删除零件再补回来**
- 编辑模式，按 `2` 边层级，点选任意一条边；
- 按 `X` → `Edge` 删除这条边 → 出现一个"缺口"；
- 按 `Ctrl+Z` 撤销复原。

**9. 养成"建模前先 Apply"的习惯（今天要背下来的动作）**
- 随便对一个物体做 `G/R/S`，然后**固定流程**：
  1. 回物体模式（确保在物体模式）；
  2. `Ctrl+A → All Transforms`；
  3. `Tab` 进编辑模式开始干；
- 重复 3 遍，直到不用想就能做出来。

**10. 挑战：做一个"两截的柱子"**
- 立方体 → `S` `X` `0.4` 变细 → `Tab` 检查；
- 回物体模式 `Ctrl+A → All Transforms`（**必须先做！**）；
- 进编辑模式 → 按 `3` → 全选顶面 `A` → `E` `Z` `2` 向上挤出；
- 回到物体模式看整体 → 一个细长的两截柱子。
- 说明：**这就是以后做瓶盖、柱子、桌腿的最基础流程**，第 9 课会专门讲 `E` 挤出。

## 六、小提示与常见坑

- **坑 1：按 `Tab` 没反应。** 99% 是因为**没选中物体**，或者选中的不是"亮橙色 Active 物体"。先左键点它。
- **坑 2：按 `E` / `Ctrl+B` 没反应。** 模式不对。看左上角是 Object Mode 还是 Edit Mode。
- **坑 3：不 Apply 就直接建模。** 这是新手最隐蔽的坑——**当下看不出问题，等加了倒角/阵列/细分才爆雷**。养成"变过形 → 先 Apply"的条件反射。
- **坑 4：以为 `Ctrl+A` 是"全选"。** 在编辑模式里 `A` 才是全选；`Ctrl+A` 在物体模式是"应用变换"，在别的地方（如雕刻）又是另一样东西。**看模式判断含义。**
- **坑 5：编辑模式里看到修改器变灰，以为坏了。** 正常现象，`Tab` 回去就恢复。
- **坑 6：在编辑模式里想搬整个物体。** 做不到——编辑模式只能动点/线/面。想搬整体，先 `Tab` 回物体模式。
- **坑 7：`Ctrl+A` 应用位置导致的"物体跳回原点"。** 用 **All Transforms** 时，Location 也会被应用，物体原点归到世界原点，模型可能"看起来位置变了"。如果你只想清掉缩放和旋转，用 **Rotation & Scale**。
- **心态提示**：本课没有新模型，看起来"很水"，但它是**整门课的地基**。往后每一节课（挤出、环切、倒角、修改器）都会默认你已经懂"模式 + Apply"。今天偷的懒，后期会用十倍时间还。
